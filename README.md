# CS5228 Study Guide

Chinese explanations, bilingual cheat sheet, and practice exercises for CS5228 Lecture 1–6. An independent study resource, not an official NUS website or past-exam archive.

- `index.html`: site entry
- `cs5228-study.html`: study guide and cheat sheet previews
- `cs5228-practice.html`: public exercise links and original practice questions
- `cs5228-bilingual-cheat-sheet.pdf`: printable bilingual reference

Serve these files as a static site. For GitHub Pages, select Settings → Pages → Deploy from a branch → main → /(root).

Progress and practice answers are stored only in the visitor's browser. Original lecture PDFs and private local files are not included. Linked external materials retain their original authorship.
