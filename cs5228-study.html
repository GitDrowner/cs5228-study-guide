LECTURE 01 / INTRODUCTION & OVERVIEW

先问：这些数据代表什么？

数据挖掘的目标，是从已有数据中找到能推广到新数据的规律。数据质量和表示方式，决定后面的算法是否在解决正确的问题。

属性类型EDA预处理

1. 找到模式，不等于发现知识

随机数据里也能找到巧合。一个有用的模式应该有意义，并且能在未见过的数据上保持有效，这就是泛化（generalization）。例如，冰淇淋销量和溺水人数一起上升，可能因为天气变热，而不是冰淇淋导致溺水。

判断题抓手：相关不等于因果；训练集表现好不等于泛化好；查找数据库中的电话号码通常只是查询，不是挖掘未知模式。

2. 四类属性：能对它做什么运算？

类型含义例子要点
Nominal 名义只有类别区别ID、邮编、眼睛颜色能判断相同/不同，不能解释大小或差值
Ordinal 有序有自然顺序满意度、学历等级“高一级”不一定有相同的量化差距
Interval 区间差值有意义，无绝对零点摄氏温度、日历日期20℃ 不是 10℃ 的“两倍热”
Ratio 比率差值、比值都可解释重量、长度、年龄20kg 是 10kg 的两倍

看语义，不看存储类型。邮编即使用整数保存也只是标签；把“差、一般、好”编码为 1、2、3，并不能证明类别之间等距。

3. EDA：先认识数据，再建立模型

探索性数据分析（Exploratory Data Analysis）用于检查分布、缺失值、重复记录、类别比例和变量关系。直方图看分布，箱线图看单变量异常，散点图看变量间关系。

  • Noise 噪声：测量误差等对信号的扰动。
  • Outlier 离群点：显著不同于其他记录的点。它可能是错误，也可能是要发现的欺诈交易。
  • Missing value 缺失值：“没有记录”不等于数值 0。填补策略需要结合业务。
  • Duplicate 重复记录：不同记录可能指向同一个现实对象，需要合并或去重。
别机械删除异常值。单个属性正常，不代表组合正常；单变量箱线图无法发现所有多变量异常。分布奇怪是调查线索，不是数据出错的证明。

4. 预处理：改变数据，让方法适用

操作做什么目的
Cleaning 清洗处理缺失、重复、错误单位提高数据质量
Reduction 约简抽样、特征选择、降维减少数据或计算量
Aggregation / Smoothing按年汇总、用箱内均值替代原值简化细节，降低部分噪声
Discretization 离散化年龄 → 青年/中年/老年连续值转有序类别
One-hot encoding类别 → 多个 0/1 特征避免给名义类别强加数值顺序
Min–max: x′ = (x − xmin) / (xmax − xmin)
Z-score: x′ = (x − μ) / σμ 为均值，σ 为标准差；常数特征的分母为 0，需要单独处理。
手算例题

某特征的训练范围为 10–50，x = 30 的 min–max 值为 (30−10)/(50−10) = 0.5。若训练均值为 25、标准差为 5，则 z-score = 1，即高出训练均值 1 个标准差。

尺度会影响欧氏距离：收入的数值可能比年龄大几千倍，未缩放时距离容易被收入支配。因此 KNN、K-Means 特别需要关注尺度。标准化并不会自动把数据变成正态分布。

与第 5 讲连接：先划分训练/验证/测试数据，再只在训练数据上拟合预处理参数。测试值超出训练 min–max 范围时，变换结果可以小于 0 或大于 1。

① 什么是知识发现 / 数据挖掘：DIKW 与 KDD 流程p.13–15

讲义采用的定义（Frawley et al., 1991）：从数据中非平凡地提取隐含的、先前未知的、可能有用的信息。三个关键词逐一对应“什么不算数据挖掘”。

数据 → 信息 → 知识 → 智慧（讲义超市例子）

层级例子理解了什么
Data2023-08-15T15:05:30Z；1.2933, 103.7844原始记录，没有语境
Information某顾客 8 月 15 日在 FairPrice NUH 买了面包、麦片、牛奶理解关系（relationships）
Knowledge很多顾客经常同时买牛奶和麦片理解模式（patterns）
Wisdom据此优化商品摆放、动态定价、捆绑促销理解原理（principles）并行动

KDD 流程（Fayyad et al., 1996）

Data →Selection→ Target Data →Preprocessing→ Preprocessed Data →Transformation→ Transformed Data →Data Mining→ Patterns →Post-processing→ Knowledge

  • Selection：找出与任务相关的数据。
  • Preprocessing：处理缺失、去重、特征选择、归一化……
  • Transformation：转换为适合算法的表示。
  • Data Mining：聚类、分类、回归、关联、相关分析……
  • Post-processing：可视化、解释、理解。

数据挖掘只是整条流程中的一步；本讲后半部分（数据质量、EDA、预处理）讲的都是它前面的步骤。

什么不是数据挖掘（p.15）

  • 平凡的提取：在电话簿里查号码；按专业给学生分组；算公司总销售额。这些是查询或统计，答案的“形式”事先已知。
  • 不产生新模式的分析：监测病人心率是否异常（规则已知）；使用搜索引擎（检索已有信息）。
Quick Quiz · p.20（答案 D）

给定超市交易数据，哪个“不算”真正的数据挖掘？A 找最常一起购买的最大商品集合（频繁项集）、B 按购买行为找相似用户（聚类）都是在发现未知模式。D “周末晚 6 点后最常卖的商品”只是先过滤、再计数排序，一条 SQL 查询就能完成，属于平凡的聚合统计。

② 什么样的模式有用：泛化、虚假相关与混杂变量p.16–19

“只要拷问数据足够久，它什么都会招。”（Coase）主要目标是泛化：模式要在没见过的数据上仍然准确。常见破坏原因是数据太少或数据有偏。

讲义例子 · 决策树判定哺乳动物

体温恒温 → 胎生 → 四足 → mammal。这棵树在训练动物上可能完全正确，但人（不是四足）会被判为 non-mammal，鸭嘴兽（卵生）也会被判错。训练数据里没有这类样本，规则就学得过窄 —— 这正是泛化失败。

数据里总能找到“模式”（p.17）

讲义列举了《Predictive Analytics》里的“惊人发现”：女性名字的飓风致死更多、用 Chrome/Firefox 的员工表现更好、素食者更少误机、冰淇淋销量高时鲨鱼袭击多……它们都是相关，不能说明因果。

  • Confounding variable 混杂变量：气温升高同时导致冰淇淋销量和下水人数（从而鲨鱼袭击）上升。
  • Spurious correlation 虚假相关：两个变量之间看似有关系，实际上由第三个因素或纯巧合造成。

Reality check（p.18）

“冰淇淋销量越高，鲨鱼袭击越多”和“抗缪勒管激素浓度越高，促卵泡激素浓度越低”在形式上完全一样。我们会觉得前者荒谬、后者可信，只是因为背景知识不同。讲义提醒：“这不合理！”很少是好的论证——判断模式要看数据来源、样本、机制与验证，而不是直觉。

p.19 引用《侏罗纪公园》：“只顾着能不能做，没想过该不该做。”数据挖掘也涉及伦理：能从数据中推断出的东西，不一定应该去推断（见 p.64–67 的 Quiz）。

⑥ 数据质量四大问题：噪声、离群点、缺失值、重复p.40–43

Noise：数据 = 真实信号 + 噪声

  • 故障传感器读数（以及固有噪声、外界干扰）
  • 人或机器录入错误；传输错误
  • 格式不一致：ISO 时间 vs Unix 时间；DD/MM/YYYY vs MM/DD/YYYY
  • 约定不一致：米 vs 英里，米 vs 厘米

Outliers：两种截然不同的处理

  • 情况 1 · 离群点是噪声：会干扰分析 → 尝试删除，或使用对离群点不敏感的方法。
  • 情况 2 · 离群点就是目标：信用卡欺诈、入侵检测——要找的恰好是罕见、异常的点。

Missing values

原因：没有采集（传感器坏了、有人拒绝报告年龄）；或属性不适用（儿童没有收入）。处理方式：

  1. 删除含缺失值的数据点；
  2. 删除含缺失值的属性（并非所有属性都同样重要）；
  3. 尝试填补（例如用附近传感器的平均温度）。

讲义表中 9 条记录有 2 个年龄缺失、3 个收入缺失。按“删除数据点”会丢掉 5 条中的大部分信息；按“删除属性”则失去收入这一可能很重要的特征 —— 两者都有代价，需要结合任务权衡。

Duplicates

  • 完全重复：属性值完全相同，较容易消除。
  • 近似重复：同一个人但电话号码格式不同等，一般非常困难。

重复在合并多个异构数据源时尤其严重；去重算法超出本课范围。

⑧ 预处理：清洗、约简、分箱平滑的完整算例p.56–59

三个目的：提高数据质量（Garbage in, garbage out）；为算法生成合法输入；降低复杂度以便分析。四项核心任务：cleaning、reduction、transformation、discretization。

Data cleaning

删除或填补缺失值；识别并删除离群点（如果离群点不是分析目标）；识别并删除/合并重复；纠正错误和不一致（如英寸转厘米）。这些任务都不平凡，且高度依赖应用。

Data reduction 的三个层面

  • 减少数据点：抽样（随机或分层），常用于初步分析或数据极大时。
  • 减少属性：删除无关属性（如 ID，或宗教、性取向等伦理上有问题的属性）；降维（PCA、LDA、t-SNE 等）。
  • 减少属性取值（一种去噪）：聚合/泛化；分箱平滑。

聚合 / 泛化

数值属性沿概念层级上移（天 → 年）；类别属性泛化（如城市 → 国家）。

Discretization（p.62）

把连续属性变成 ordinal：有些算法只接受类别属性；也可以把回归任务变成分类任务。讲义用 3 个人工设定的区间把体重分为 light (0, 70]、average (70, 90]、heavy (90, 150]：86 → average，57 → light，103 → heavy。

聚类，是给“相似”一个定义。

没有预先给定的标签。你选择距离、簇的形状假设和算法，算法才知道怎样把数据分组。

K-MeansDBSCANAGNES

1. K-Means：让点靠近自己的中心

给定 K 个簇，K-Means 试图减小每个点到所属簇中心的平方距离总和：

SSE = ∑k=1K ∑x∈Cₖ ‖x − μk‖²
μk = (1 / |Ck|) ∑x∈Cₖ x
  1. 初始化：选择 K 个中心。
  2. Assignment：把每个点分给最近的中心。
  3. Update：把中心移到该簇所有点的均值。
  4. 重复分配和更新，直到分组不再变化。

为什么用均值？固定一个簇时，均值最小化簇内平方误差。为什么会收敛？分配与更新都不会增加 SSE。但它通常只到达局部最优，不保证全局最佳分组。

方法改变了什么记忆点
K-Means++优化初始化新中心的抽样概率 ∝ 到最近已有中心的距离平方；不是每次直接选最远点

K-Means 的假设和局限：偏好紧凑、近似球状的簇；对初始化、尺度、离群点和大小/密度差异敏感。增大 K 往往降低最优 SSE，所以不能只靠最小 SSE 选 K。

2. DBSCAN：沿着稠密区域扩展

参数 ε 定义邻域半径，MinPts 定义形成稠密区域的最低点数。本课讲义的邻域包含该点自身。

点类型判断规则是否继续扩展
Core 核心点ε 邻域中的点数 ≥ MinPts是
Border 边界点不是核心点，但落在某核心点的 ε 邻域内否
Noise 噪声点以上都不是否

从一个核心点出发，吸收邻居，再从新发现的核心点继续扩展。边界点不能当桥梁继续连接。探索初期暂标为噪声的点，后来可能被某核心点吸收，成为边界点。

手算例题

MinPts = 4。某点附近有 3 个其他点，连同自身共 4 个，因此是核心点。若所有点都没有足够邻居，DBSCAN 可以输出 0 个簇，全部点为噪声。

它能发现非球状簇，不需预先指定 K；但同一组 ε、MinPts 难以同时适配密度差异很大的簇。k-distance 曲线的拐点可帮助初选 ε。

是否确定？给定数据与参数，核心点身份及核心点连接结构固定；若边界点邻接两个不同簇，它的归属可能取决于访问顺序。忽略簇编号后，也不保证全部成员完全一致。

3. AGNES：把最近的两簇不断合并

凝聚型层次聚类从“一点一簇”开始，每次合并最接近的两簇，形成 dendrogram（树状图）。在不同高度切开树，就得到不同数量的簇。关键是：簇与簇的距离如何定义？

Linkage定义主要特点
Single两簇点对距离的最小值能连接细长形状；易被噪声串成链
Complete两簇点对距离的最大值偏好紧凑簇；可能拆散较大的自然簇
Average所有跨簇点对距离的平均值折中；不是两个质心间的距离
Centroid两个簇均值之间的距离直接比较中心
Ward合并造成的 SSE 增量优先选择最少增加簇内误差的合并
ΔSSE(A, B) = [|A||B| / (|A| + |B|)] · ‖μA − μB‖²
手算例题

A = {1, 2}，B = {6, 8}。跨簇距离为 5、7、4、6，因此 single = 4，complete = 7，average = 5.5。两簇均值为 1.5、7，所以 Ward 的 SSE 增量为 (2×2/4)×5.5² = 30.25。

距离矩阵需要 O(N²) 空间。朴素实现 N−1 次合并、每次扫描距离矩阵，时间 O(N³)；更好的数据结构或特定 linkage 可加速。

补充复习：怎样评价聚类？

第 3 讲 p.5 提到：有真实标签时可用 purity、Rand index；没有标签时可用 SSE 肘部法、轮廓系数。

s(i) = [b(i) − a(i)] / max(a(i), b(i))

a(i) 为该点到同簇其他点的平均距离；b(i) 为它到其他每个簇的平均距离中的最小值。s 接近 1 表示分离较好，接近 0 表示靠近边界，负值提示分组可能不合适。单点簇通常约定为 0。这些指标也有形状偏好，不能取代任务判断。

② 聚类的概念：簇的类型与聚类结果的类型p.9–18

目标：把无标签数据分成相似对象组成的组，最大化簇内相似度、最小化簇间相似度。聚类提供数据的中观（meso）视角：介于单个数据点（micro）与整个数据集（macro）之间。

应用：市场细分（对同一簇客户推送定制促销）；推荐系统（按类型、时长、预算等把电影聚类，推荐用户喜欢的电影所在簇）；网页搜索多样化（从不同簇中返回结果，保证多样性）。

三个要素（p.11）

对象表示对应的相似度
多维点坐标 x, y欧氏距离
集合 A, B（如一笔交易的物品）Jaccard 相似度 = |A∩B| / |A∪B|
向量 u, v（如 TF-IDF）余弦相似度 = u·v / (‖u‖‖v‖)

再加上聚类算法：决定对象是否属于某个簇的过程。p.12 的同一组点可以合理地看成 2、3 或 5 个簇 —— “好”的聚类并不唯一。

簇的四种类型（p.13–14）

  • Well-separated：簇内任一点与簇内每个点的距离，都比与簇外任何点更近（最严格）。
  • Center-based：每个点离自己簇的“中心”比离其他簇的中心更近；欧氏空间中心常取均值，称 centroid（K-Means 的假设）。
  • Contiguity-based：两点足够相似就在同一簇；每个点至少与簇内某个点比与簇外点更相似（可形成链状，类似 single linkage）。
  • Density-based：簇是被低密度区域包围的高密度区域；通常比 contiguity-based 更能处理噪声（DBSCAN 的假设）。

聚类结果的三组对比（p.15–17）

③ K-Means：目标函数、为什么中心是均值、收敛过程p.20–27

特征：簇是 centroid-based；聚类结果是 partitional、exclusive、complete。输入是 d 维欧氏空间中的点 x1…xN 和簇数 K，输出 K 个中心 c1…cK。

SSE = ∑i=1K ∑x∈Ci ‖x − ci‖²

找到全局最优是 NP-hard 的（讲义板书：精确求解约 O(NKd+1)），因此用贪心算法 —— Lloyd's algorithm。

为什么中心取均值（p.22 推导）

固定分组，对某个中心 ck 求导，只有第 k 个簇的项与它有关：

∂SSE/∂ck = ∑x∈Ck 2(ck − x) = 0
⇒ mk·ck = ∑x∈Ck x ⇒ ck = (1/mk) ∑x∈Ck xmk = |Ck|。结论：欧氏距离平方下，簇中心 = 簇内所有点的均值。

Lloyd 算法（p.23–25）

  1. 初始化：选 K 个点作为初始中心。
  2. 重复：2a Assignment——每个点分给最近的中心；2b Update——每个中心移到所分配点的均值。
  3. 直到分配不再改变。

收敛过程中的 SSE（p.26 讲义数字）

4.61 →(U) 3.26 →(A) 2.24 →(U) 0.77 →(A) 0.55 →(U) 0.45 →(A) 0.42 →(U) 0.39 →(A) 0.39 →(U) 0.38 →(A) 0.38 →(U) 0.38。

  • 好消息：K-Means 一定收敛。Assignment 在中心固定时让每个点选最近中心，SSE 不增；Update 在分组固定时取均值，是该分组下 SSE 的最小值，也不增。分组的可能数量有限，所以不会无限循环。大部分改进发生在前几轮。
  • 坏消息：只保证局部最优，不保证全局最优；结果依赖初始化。
④ K-Means 的局限：分布假设、初始化、空簇 + 两道 Quizp.28–31, 35

对“自然”簇敏感（p.28）：非球状簇（如月牙形）、大小差别很大的簇、密度差别很大的簇，K-Means 都容易切错。原因是它按“离哪个中心最近”划分，边界是两中心的垂直平分线。

初始化影响结果（p.29）：同一份数据三次不同初始化，得到 SSE 分别为 0.38、0.94、0.54 的三种聚类。实践中常多次随机初始化，取 SSE 最小的一次。

空簇（p.30）：如果一个中心被其他中心“挡住”，没有任何点离它最近，它就得到空簇，而且之后位置不会再更新。

Quick Quiz · p.31（答案 B：K − 1）

每个点总要分给某个最近的中心，所以至少有一个簇非空。最坏情况下，所有点都离同一个中心最近，其余 K − 1 个簇全空。

Quick Quiz · p.35（答案 A：No）

即使初始化“理论最优”，也不能保证任何情况下都没有空簇。最简单的反例：数据中不同的点少于 K 个（如大量重复点），那么无论中心怎么放，都不可能让 K 个簇都非空。

⑤ K-Means++、K-Medoids、X-Means 细节p.32–34

K-Means++（只改初始化）

  1. 随机选一个点作第一个中心。
  2. 重复：对每个点 x 计算 D(x) = 到最近已有中心的距离；按 正比于 D(x)² 的概率随机选下一个中心。
  3. 直到选够 K 个。

目的是让中心分散开；实践表现更好，并且有理论保证（期望 SSE 在最优解的 O(log K) 倍以内 补充）。讲义图中离已有两个中心都很远的点“最有可能成为第 3 个中心”——是概率最高，不是一定选中。

小算例 补充

一维点 0、1、10，第一个中心选 0。D² 分别为 0、1、100，第二个中心选中 10 的概率 = 100/101 ≈ 0.99，选中 1 的概率 ≈ 0.01。

K-Medoids（灵活性 vs. 性能）

  • 中心（medoid）必须是真实数据点，不需要求平均（集合、字符串等复杂对象无法求平均）。
  • 只需要距离或相似度的概念，不限于欧氏距离。
  • 对噪声和离群点更鲁棒（中心不会被极端值拉走）。
  • 主要问题是性能：Update 步要把 medoid 与簇内每个点试着交换，计算代价（如 SSE）的变化，选交换后代价最小的点作新 medoid。

X-Means（自动选 K）

先用 K = 2 运行 K-Means；然后对每个子簇再用 K = 2 运行；只有当拆分按评分函数“有意义”时才真正拆分。评分函数例子：BIC、AIC、MDL —— 它们在拟合程度与模型复杂度之间权衡，避免无限拆分。

⑥ DBSCAN：两阶段算法与讲义伪代码p.37–42

特征：density-based 簇；结果是 partitional、exclusive、partial（噪声点不属于任何簇）。输入：点集、半径 ε、最少点数 MinPts。

三类点（p.38）

  • Core：ε 邻域内至少 MinPts 个点（包括自身），构成簇的内部。
  • Border：非核心点，但邻域内至少有一个核心点，构成簇的边界。
  • Noise：其他所有点；也是算法中点的默认标签。

Phase 1：找新的簇种子（p.39）

随机挑一个未探索的点 x；若它的邻居少于 MinPts，就标为 noise（之后可能被改）；重复直到找到一个新的核心点 xc。讲义动画：第 1、2、3 次挑到的都是噪声，第 4 次挑到核心点。

Phase 2：探索簇（p.40–42 伪代码）

S ← get_neighbors(x_c, ε)
WHILE |S| ≠ 0:
    s ← S.pop()
    IF s.label = "noise":   s.label ← x_c.cluster_id   # 噪声被改为边界点
    IF s.label ≠ "unknown": CONTINUE                  # 已探索过
    s.label ← x_c.cluster_id
    neighbors ← get_neighbors(s, ε)
    IF |neighbors| ≥ MinPts:  S ← S ∪ neighbors        # s 也是核心点，继续扩展

核心点的所有邻居都进入同一簇，邻居要么是核心点、要么是边界点，绝不会是噪声。扩展在边界点处停止；边界点之外的点，之后在 Phase 1 中要么成为噪声，要么成为新簇的一部分。

⑦ DBSCAN 的性质、局限、参数选择 + Quizp.43–50

课堂活动：DBSCAN 是确定性的吗？（p.43–44）

  • 总会收敛：每个点都会被探索（在 Phase 1 或 2），且点的类型不会改变，唯一例外是 noise → border。
  • 不完全确定：Phase 1 引入随机顺序。核心点和噪声点是确定的；但一个边界点可能同时位于两个不同簇的核心点邻域内，它归哪一簇取决于哪个簇先被探索。

局限（p.45–46）

无法处理不同密度的簇：ε 小了稀疏簇变噪声，ε 大了稠密簇连成一片。对参数非常敏感：讲义三张图 MinPts 相同、ε 稍有不同，结果差异很大。

如何选参数（p.47–48）

  • k-distance 图：计算每个点到第 k 个最近邻的距离，排序后作图，取“肘部”处的距离作为 ε 的初始值。
  • MinPts 经验值：维度数的 2 倍。
  • 利用语义：若密度有直观含义，直接由任务定参数。讲义例子：新加坡 141 家麦当劳，找“500 m 半径内超过 5 家”的区域 → ε = 500 m，MinPts 由“超过 5 家”确定。类似地，“500 m 内超过 10 家酒吧”的区域。
Quick Quiz · p.49（答案 A：0）

N = 1000、MinPts = 10 时，最少可能有 0 个簇：如果点分布稀疏，没有任何点的 ε 邻域达到 10 个点，就没有核心点，所有点都是噪声。

Side Note · p.50

不同资料对 “neighbors 是否包含 s 自身” 不一致。原始论文：包含。由此：最小簇大小 = MinPts（一个核心点的邻域就有 MinPts 个点）；最大簇数 = ⌊N / MinPts⌋。考试时按讲义约定（包含自身）作答。

⑧ 层次聚类与 Dendrogram + 深度 Quizp.52–57

特征：簇的类型取决于所用 linkage；结果是 hierarchical、complete，并且在每一层上是 exclusive。原则上无需参数；实践中通常仍会指定簇数（类似 K-Means）。讲义例子：NUS Students ⊃ Undergraduate Students ⊃ CS Majors / EE Majors。

Dendrogram：二叉树，每个节点是一个簇，每个叶子是单点簇，节点高度 = 合并时两簇的距离。在某个高度水平切一刀，与切线相交的竖线数就是簇数（讲义示例：切得高得到 2 簇，切得低得到 4 簇）。

Agglomerative（自底向上）AGNESDivisive（自顶向下）DIANA
每个点一个簇开始，每步合并最近的两簇，直到只剩一个簇所有点一个簇开始，每步拆分一个簇，直到每簇只有一个点
Quick Quiz · p.56（答案 A：Min log₂N，Max N）

每次合并两个簇。若每次都把大小相同的簇两两配对，树是平衡二叉树，深度约 log₂N；若每次都把一个新点并入同一个大簇，树退化成一条链，深度为 N − 1，即 O(N)。

Quick "Quiz" · p.60

“下一步应合并哪两个簇？”没有唯一答案 —— 取决于如何定义簇间距离。红、蓝两簇各有一个点离得很近，按 single linkage（最近点对）应合并红与蓝；但红、蓝整体跨度大，按 complete linkage（最远点对）可能是红与品红更近。这引出了各种 linkage。

买了 X 的人，也常买 Y 吗？

输入是一组交易，每笔交易是一组物品；输出是 X → Y 的共现规律。规则两侧非空且不重叠，不表达因果关系。

Support / Confidence / LiftApriori反单调性

1. 三个指标，分别回答三个问题

Support(X → Y) = S(X ∪ Y)
Confidence(X → Y) = S(X ∪ Y) / S(X) = P(Y | X)
Lift(X → Y) = S(X ∪ Y) / [S(X)S(Y)] = Confidence / S(Y)
指标直觉注意
Support 支持度一起出现，覆盖多少交易？规则 X→Y 和 Y→X 的支持度相同
Confidence 置信度出现 X 后，Y 有多常见？有方向；Y 本身很常见时也可能很高
Lift 提升度比 Y 原本的流行程度高多少倍？>1 正关联；=1 该事件组合独立；<1 负关联

2. Apriori 的核心：先找频繁项集

d 种物品有 2d−1 个非空项集；允许两侧都是多物品时，有 3d−2d+1+1 条可能规则。枚举成本很高，因此把任务拆成两步：

  1. 找到 support ≥ minsup 的频繁项集。
  2. 将频繁项集拆成规则，只保留 confidence ≥ minconf 的规则。
A ⊆ B ⇒ S(A) ≥ S(B)包含 B 的每笔交易一定也包含 A；要求的物品越多，满足条件的交易不会更多。

由此得到两个方向：频繁项集的所有子集都频繁；不频繁项集的所有超集都不频繁。反过来，“所有子集频繁”不保证整个项集频繁。

算法步骤：Generate → Prune → Count → Filter

  1. Generate：从上一轮频繁项集 Fk−1 生成候选 k 项集 Lk。本课用 L 表示候选集。
  2. Prune：若某候选的任一 (k−1) 项子集不在 Fk−1 中，直接删除。
  3. Count：扫描交易，计算剩余候选的支持计数。
  4. Filter：删除支持度不足的项集，得到 Fk；若为空则结束。

剪枝的价值是减少昂贵的数据库计数操作。可用 Fk−1×F1 扩展，或用重叠 k−2 个物品的两个 (k−1) 项集连接，再去重和剪枝。

手算例题 / 完整一轮

交易：T₁={A,B,C}，T₂={A,B}，T₃={A,C}，T₄={A,B,C}，T₅={B}。minsup=0.6，所以至少出现 3 次。

单项：A=4、B=4、C=3，全部频繁。两项：AB=3、AC=3、BC=2，因此 F₂={AB, AC}。候选 ABC 包含不频繁的 BC，不必扫描交易就能剪掉。

AB 产生 A→B 与 B→A。二者支持度均为 3/5=0.6，置信度均为 3/4=0.75；如果 minconf=0.8，则这两条规则都不能保留。

3. 规则生成也能剪枝，但条件要说完整

固定同一个频繁项集 S，把它拆成 X→(S−X)。若扩大后件，就会缩小前件；分子 S(S) 不变，分母 S(X) 不会减小，因此置信度不会增加。

规则剪枝

固定 S={A,B,C,D}。如果 ABC→D 置信度不足，则 AB→CD、A→BCD 等所有“后件包含 D”的规则都不够。这个结论要求整个项集 S 固定，不能随便比较两个来自不同项集的规则。

一个大小为 k 的频繁项集有 2k−2 条非空二分规则。计算置信度可复用频繁项集阶段的计数，无需再次扫描交易。

三个常见陷阱：lift 不具备这里所需的反单调性，不能直接照搬支持度剪枝；单项集虽然不能单独构成规则，但其计数用于置信度和 lift；有效规则必须同时满足两个阈值，任一个不满足都应淘汰。

Quick Quiz · p.22（答案 C）

对任意规则 R，有 S(R) ≤ C(R)。因为 C(R) = S(X∪Y)/S(X)，而 0 < S(X) ≤ 1，除以一个不超过 1 的数只会让值变大或不变。仅当 X 出现在所有交易中（S(X) = 1）时二者相等，所以 “<” 不总是成立，“≤” 才对。

③ 暴力法到底有多贵：规则数公式的推导p.13, 24–26, 30–31

暴力算法：列出所有可能规则，逐条算 S 和 C，淘汰不达标的。讲义 p.24 写的是 “S < minsup and C < minconf 时丢弃”，按目标（两个阈值都要满足）应理解为：任一个不达标就丢弃。

为什么 d 个物品有 3d − 2d+1 + 1 条规则？

每个物品有三种去向：放进 X、放进 Y、或都不放。共 3d 种分配。其中要扣掉 X 为空的分配（每个物品只能去 Y 或不放：2d 种），再扣掉 Y 为空的 2d 种；X、Y 同时为空的那 1 种被扣了两次，要加回：

#rules = 3d − 2·2d + 1 = 3d − 2d+1 + 1 ∈ O(3d)d = 6：729 − 128 + 1 = 602。

只看“真实出现过”的规则（p.26）

一条规则只有在某笔交易同时包含 X 和 Y 时支持度才大于 0。令 w 为单笔交易最多物品数，每笔交易最多贡献 3w − 2w+1 + 1 条规则，总计 O(N·(3w − 2w+1 + 1))，通常 w ≪ d。

④ 拆成两步：为什么先找频繁项集就够了p.27–29

Observation 1：S(X → Y) = S(X ∪ Y) 只取决于并集，与怎样拆成 X、Y 无关。所以如果 X∪Y 不是频繁项集，从它拆出的每一条规则都支持度不足，根本不用算置信度。

  1. Part 1 · 频繁项集生成：找出所有 S ≥ minsup 的项集。候选“只有” 2d − 1 个非空项集，比 3d 条规则少得多。
  2. Part 2 · 规则生成：对每个频繁项集做二分，只保留 C ≥ minconf 的规则。

Itemset lattice（项集格）：每个节点是一个项集，边表示包含关系（{ABCD} 包含 {ABC}）。d = 5 时共 25 − 1 = 31 个节点。Apriori 的剪枝就是在这张格上“整片剪掉”。

⑤ Apriori 原理：反单调性的两个方向p.34–36
X ⊆ Y ⇒ S(X) ≥ S(Y)

讲义例子：S({bread, yogurt}) = 3/5，而多加一个 milk 后 S({bread, yogurt, milk}) = 2/5。要求越多，满足的交易只会更少或相等。由此得到两句话（互为逆否）：

  • 向下：若 {B,C,D,E} 频繁，则它的所有子集（{B,D,E}、{C,E} ……）都频繁。
  • 向上：若 {A,B} 不频繁，则它的所有超集（{A,B,D}、{A,B,C,D} ……）都不频繁 —— 在项集格上把以 {A,B} 为根的整个上方区域剪掉。

“反单调（anti-monotone）”说的是：项集变大，支持度不增。Apriori 利用的正是第二个方向。

⑦ 从 Fk−1 到 Lk：两种候选生成法p.44–46

方法一：Fk−1 × F1

把每个频繁 (k−1)-项集与每个频繁物品合并，得到所有可能的 k-项集。以 k = 3 为例，讲义得到 10 个候选：{bread, cereal, cheese}、{bread, cereal, milk}、{bread, cereal, yogurt}、{bread, cheese, milk}、{bread, cheese, yogurt}、{bread, milk, yogurt}、{cereal, cheese, milk}、{cereal, cheese, yogurt}、{cereal, milk, yogurt}、{cheese, milk, yogurt}。剪枝后剩 5 个（见上一节表格）。

方法二：Fk−1 × Fk−1

只合并恰好重叠 k−2 个物品的两个频繁 (k−1)-项集。k = 3 时，两个 2-项集需要共享 1 个物品，例如 {bread, cereal} + {bread, milk} → {bread, cereal, milk}。这一步本身就利用了“两个子集都频繁”，候选通常更少；讲义得到 9 个（同一候选可能由不同对生成，如 {cheese, milk, yogurt}，需去重），剪枝后同样剩 5 个。

常见实现 补充：把物品按固定顺序排好，只合并前 k−2 个物品完全相同的两个项集，这样每个候选只会被生成一次，无需去重。

Prune 规则（两种方法相同）

删除任何一个 (k−1)-子集不在 Fk−1 中的 k-项集。一个 k-项集有 k 个 (k−1)-子集，都要检查。

Calculate：计算支持计数

对每笔交易 T、每个候选 s，若 s ⊆ T 就给 s 的计数器加一。这需要完整扫描数据库，是要尽量减少的一步。高效实现（如哈希树）属于实现层面，本课不要求。

⑧ 规则生成：置信度剪枝与讲义伪代码p.47–54

对每个频繁项集 S，候选规则是 S 的二分 X → Y，其中 Y = S − X，X、Y 都非空，共 2|S| − 2 条（|S| = 4 时 14 条）。置信度 C = SC(S)/SC(X)，两个计数在 Part 1 已算好 —— 不需要再访问数据库，所以很快。

为什么可以剪枝（p.49）

取同一个 S 拆出的两条规则 X1→Y1、X2→Y2（X1∪Y1 = X2∪Y2 = S）：

C(X₁→Y₁) = S(S)/S(X₁)，C(X₂→Y₂) = S(S)/S(X₂)
X₁ ⊆ X₂ ⇒ S(X₁) ≥ S(X₂) ⇒ C(X₁→Y₁) ≤ C(X₂→Y₂)

前件越小（后件越大），置信度越低。所以若 {A,B,C}→{D} 置信度不足，则所有后件包含 D 的规则 {A}→{B,C,D}、{B}→{A,C,D}、{C}→{A,B,D}、{A,B}→{C,D}、{A,C}→{B,D}、{B,C}→{A,D} 都不足。在规则格上（p.50）：若 BCD→A 不合格，则后件包含 A 的整片规则都剪掉。

讲义伪代码（单个项集 S）

YS = { {s} | s ∈ S }              # 从单物品后件开始
repeat:
    YS_valid = evaluate(S, YS, minconf)
    YS = generate(YS_valid)        # 用合格后件合并出大一号的后件

⑨ Lift：控制后件本身的流行度p.56–58
L(X → Y) = C(X → Y) / S(Y) = S(X ∪ Y) / [S(X) · S(Y)]

注意讲义 p.56 的交易表把 T2、T4 的物品顺序换了写法，但集合相同。

讲义例题展开

L({cereal}→{bread}) = S({cereal, bread}) / [S({cereal}) · S({bread})] = 0.4 / (0.6 × 0.8) ≈ 0.833。

换个角度：随便抽一笔交易，含面包的概率是 S({bread}) = 0.8；已知含麦片时，含面包的概率是 C({cereal}→{bread}) = 2/3 ≈ 0.667。麦片的出现反而降低了面包的概率，所以 lift < 1。只看 0.667 的置信度，会误以为这条规则还不错。

  • 对称性 补充：分子分母关于 X、Y 对称，所以 L(X→Y) = L(Y→X)，而置信度没有这个性质。
  • 用途：对 Apriori 输出的规则做进一步过滤和排序；lift < 1 可用于寻找“替代品”。
  • 为什么 Apriori 不用 lift：lift 不满足反单调性，项集变大 lift 可以变大也可以变小，无法据此安全剪枝。
Quick "Quiz" · p.58（答案 B）

四条规则 {cereal}→{milk}、{coke}→{pepsi}、{milo}→{nutella}、{banana}→{grapes} 中，{coke}→{pepsi} 的 lift 预计最小：可乐和百事互为替代品，买了一种通常就不再买另一种，同时出现的概率低于独立假设，lift < 1。其余三组更像互补或无关商品。

⑩ 讨论：基本设定遗漏了什么？p.32, 60–61

课堂活动问：“交易 = 物品集合” 的设定缺少哪些购物行为信息？讲义 p.60 给出的方向：

  • 物品属性：数量、价格（买 1 瓶和买 12 瓶牛奶被视为一样）。
  • 顺序：加入购物车的先后（线上商店可记录）。
  • 类别层级：milk 与 yogurt 都是 dairy；在更粗的层级上可能出现更强的规则。
  • 用户信息：把多笔交易关联到同一用户，才能发现跨次购物的模式。

其他衡量规则“是否有趣”的指标：conviction、all-confidence、collective strength、leverage。常见定义 补充：

Leverage(X→Y) = S(X∪Y) − S(X)S(Y)
Conviction(X→Y) = [1 − S(Y)] / [1 − C(X→Y)]
All-confidence(Z) = S(Z) / maxi∈Z S({i})

Leverage 用“差”而不是“比”衡量偏离独立的程度；conviction 在 C = 1 时趋于无穷；all-confidence 是项集层面的指标，并且具有反单调性。

再强调一次：规则反映的是相关/共现，不是因果。{uni-grad, ≥30}→{high-income} 不说明读大学“导致”高收入。

本讲总结（p.61）

  • 关心的模式：X → Y，根据一些物品的出现预测另一些物品的出现；适用于各种交易型数据。
  • 用 support、confidence、lift 等指标判断规则是否有用。
  • 处理复杂度：把支持度与置信度的计算解耦；用 Apriori 完成频繁项集生成和规则生成两部分。

多分类：Micro 和 Macro

先把每个类别视作“正类”，其他类别视作“负类”，得到 One-vs-Rest 矩阵。Micro 先汇总各类 TP、FP、FN 再算指标，样本多的类影响更大；Macro 先分别算每类指标再取平均，各类权重相同。

对覆盖全部类别的单标签多分类，micro-precision = micro-recall = micro-F1 = accuracy。Macro-F1 则是各类 F1 的平均，不是把 macro-P 和 macro-R 代入 F1 公式。

2. KNN：用邻居的答案来预测

预测新样本时，找训练集中最近的 k 个点。分类通常用多数投票，回归通常取目标值均值。基本 KNN 几乎没有参数拟合过程，主要计算开销出现在预测时。

手算例题

某查询的 3 个最近邻标签为 Yes、No、Yes，分类结果为 Yes。如果对应回归目标为 10、13、16，则预测为 (10+13+16)/3=13。

4. 过拟合：树可以记住数据

如果不存在“特征完全相同而目标冲突”的记录，一棵足够深的树可能把训练数据拟合得很完美。代价是对训练样本的微小变化非常敏感，即高方差。

  • Pre-pruning：限制最大深度、最小分裂样本数或叶节点最小样本数。
  • Post-pruning：先长树，再依据验证表现等准则删除无益分裂。

N 个可分开的样本，每次分裂出一个样本，树可退化成链，最大深度为 N−1（根深度记为 0）。

④ KNN：算法、距离、k 的选择与 Quizp.29–41

直觉：相似的数据点有相似的标签。“训练”只是记住训练数据；预测时计算到所有训练点的距离，取最近的 k 个：分类取多数标签，回归取目标值的平均。k 通常取奇数以降低二分类平票的概率。

Euclidean： d = √∑i(xi − yi)²
Manhattan： d = ∑i|xi − yi|
Chebyshev： d = maxi|xi − yi|

还可以用余弦相似度、Jaccard 相似度或自定义度量。例：(0,0) 与 (3,4) 的三种距离分别是 5、7、4 补充。

Quick "Quiz" · p.31（答案 B）

k 要不要取质数（避免 k = 9 时 3/3/3 平票）？没必要，但也无害。只用质数会很快限制 k 的选择；三个及以上类别打平的情况本应很少，真出现了往往说明数据本身很“乱”。

Iris 分类例子（p.33–36）

3 类各 50 个样本，4 个连续特征，只用萼片长度和宽度 2 个。120 个训练样本（40 红、39 绿、41 蓝），30 个测试样本。EDA：红类分得很开，绿蓝重叠很多。不同 k 的规律：

  • k 很小：对噪声和离群点极其敏感；
  • k 较大：容量不足，无法恰当地分开类别；
  • k 非常大：训练数据中最多的类开始主导所有预测。

1-NN 与 Voronoi 图（p.35）：把空间划分为单元格，每个单元格是离某个训练点最近的所有位置。1-NN 的决策边界就是相邻单元格属于不同类别处的 Voronoi 边。

⑤ KNN 的优缺点与四个 Caveat（含归一化算例）p.43–50

优点：简单直观、效果常常出奇地好；通用——只要距离能“有意义地”度量就能用；可产生任意形状（分段线性）的决策边界；没有训练时间。缺点：测试时找邻居可能很慢（实践中用专门数据结构加速）；必须存储全部训练数据。

Caveat 1：量纲 · p.44–45

A = (80 kg, 165 cm, male)，B = (55 kg, 180 cm, female)，C = (70 kg, 180 cm, ?)。

  • 身高用 cm：d(A,C) = √(10² + 15²) ≈ 18.0，d(B,C) = √(15² + 0²) = 15.0 → C 判为 female。
  • 身高用 m：d(A,C) = √(10² + 0.15²) ≈ 10.0，d(B,C) ≈ 15.0 → C 判为 male。

只换了单位，结论就反了。用 z-score（总体标准差）：体重均值 68.33、σ ≈ 10.27 → A 1.14、B −1.30、C 0.16；身高均值 1.75、σ ≈ 0.0707 → A −1.41、B 0.71、C 0.71。于是 d(A,C) ≈ 2.33，d(B,C) ≈ 1.46 → C 判为 female，且与单位无关。

Caveat 3：非数值数据（p.49）

实际特征常是类别型（ordinal：学历、成绩；nominal：性别、婚姻状况）。基本做法是编码成数值，但编码不保证能合理表达距离/相似度，也不自动带来好结果，还可能增加维度（one-hot）。讲义表格里 “make”（应为 male）这类拼写错误也提醒要先清洗。

Caveat 4：语义相似 vs 底层相似（p.50）

非结构化数据（文本、图像、视频、音频）的对象往往“不止是各部分之和”。讲义的狗粮广告例子：两张图逐像素相似度很高、容易计算，但语义相似度很低。

⑥ 决策树：结构、预测、同一数据的不同树 + Quizp.52–58

组成：内部节点 = 对单个特征的测试；分支 = 测试结果（某个值或值域）；叶子 = 标签（分类）或实数（回归）。

预测新样本（p.54）：50 岁、PhD、Single、70k → Marital Status = Single → Annual Income ≥ 65k → YES。

Quick Quiz · p.57：遇到未知取值怎么办？

例如 Education = “Poly” 在训练时从未出现（若路径需要测试 Education 就会卡住）。讲义给出的几种做法：

  • 直接报错；
  • 在当前节点停下，使用该节点的多数标签（分类）或均值（回归）；
  • 使用 surrogate split（替代分裂）：用与原分裂结果最相似的另一个特征来分。

多样性（p.58）：分支数可以不同（Education 三路分裂；Age 分成 <20、[20,40)、[40,60)、≥60）；深度可以不同。叶子可以包含多个标签——由数据决定，或者主动选择（剪枝）——此时输出多数标签或均值。例：Education = Bachelor 叶子 3×NO；Master/PhD 叶子 5×YES、1×NO → 输出 YES。

⑦ CART 建树逐步演示 + 候选分裂的数量p.60–72

通用过程：Dt 为到达节点 t 的记录。若 |Dt| = 1 或 Dt 中所有记录标签（值）相同 → t 为叶子；否则选一个测试（特征 + 条件）把 Dt 拆小，递归处理。CART 只做二叉分裂。

候选分裂有多少个？

  • 数值特征（p.70）：Age 取值排序后为 18, 23, 26, 28, 30, 35, 41, 55（35 出现两次只算一次），在相邻不同值之间放阈值，共 7 个候选。

⑧ 选最佳分裂：Gini、Entropy、RSS 的讲义算例p.73–81

全局最优（准确率最高的树）是 NP-complete，大数据上不可行；所以用贪心：每步选让子节点不纯度最小的分裂，快但不保证最优。

节点不纯度 · p.75

(0 YES, 6 NO)：Gini = 1 − (0² + 1²) = 0；Entropy = −(0·log 0 + 1·log 1) = 0。

(4 YES, 2 NO)：Gini = 1 − [(4/6)² + (2/6)²] = 1 − 20/36 ≈ 0.44；Entropy = −(4/6·log₂4/6 + 2/6·log₂2/6) ≈ 0.92。

p.76：二分类时，两者都在 p = 0.5 取最大值（Gini 0.5，Entropy 1），在 p = 0 或 1 为 0；曲线形状相似，常常选出相同的分裂。

分裂的不纯度（p.77）：子节点不纯度按样本数加权求和：Isplit = ∑ (ni/n)·I(ti)。信息增益 IG = I(t) − Isplit，选使 Isplit 最小（即 IG 最大）的分裂；要求 IG > 0 才值得分裂。p.78 的 Gini 算例见本讲正文第 3 节。

Quick Quiz · p.79：为什么不用方差之和？

方差对样本数做了 1/N 归一化，会抹掉节点大小的影响；而我们希望像分类时一样，大节点的不纯度更有分量。本例：方差和分别为 1630/5 + 650/4 = 488.5 和 200/3 + 850/6 ≈ 208.3，结论恰好相同，但一般情况下不能保证。

欠拟合与过拟合（p.85–87）

  • 欠拟合：训练分数和测试分数都（很）低。
  • 过拟合：训练分数继续上升，测试分数开始下降。
  • 二者之间是“sweet spot”。

决策树总能完美拟合训练数据（前提：没有特征相同但标签不同的重复记录）：一直分到每个叶子只有一个样本，每个叶子都 100% 纯。解决办法是限制树的大小——剪枝：

  • Pre-pruning · 最大深度：到达最大深度就停止（讲义例：max depth = 3，更深的节点根本不会被生成）。
  • Pre-pruning · 最小样本数：节点样本少于阈值就不再分裂（讲义例：16）。
  • Post-pruning：先长完整的树，再逐个检查分裂：如果在验证集上去掉该分裂不变差（或更好），就删掉，继续检查下一个。
  • 也可以组合多种方法。

解析解：Normal Equation

θ = (XᵀX)⁻¹Xᵀy

将梯度设为 0 得到正规方程。上述逆矩阵表达式要求 X 满列秩。特征线性相关、或参数数超过样本数，都会导致 XᵀX 不可逆。

更一般可用 Moore–Penrose 伪逆 θ=X⁺y。矩阵求逆这一步约为 O(d³)，构造矩阵也要计算成本。

迭代解：Gradient Descent

∇L = (2/n) Xᵀ(Xθ − y)
θ ← θ − η∇L

梯度指向最陡上升方向，所以要减去它。η 是学习率：过大可能振荡/发散，过小可能收敛很慢。

每一步同时使用旧参数计算全部分量，再更新参数。

手算一轮梯度下降

数据 (x,y)={(1,2),(2,3)}，初始 θ₀=θ₁=0，η=0.1。预测误差为 −2、−3。

∂L/∂θ₀ = (2/2)(−2−3)=−5；∂L/∂θ₁=(2/2)(−2×1−3×2)=−8。更新得 θ₀=0.5，θ₁=0.8。若题目损失用了 1/(2n)，梯度就会少一个 2。

Batch GD 每步看全部训练数据；SGD 每步看一个样本；Mini-batch 每步看一小批。它们都是沿梯度更新，只是梯度估计的样本范围不同。普通最小二乘是凸问题；慢收敛不是“卡在坏的局部极小值”的证据。

2. 多项式回归：曲线仍然可以是线性模型

ŷ = θ₀ + θ₁x + θ₂x² + ⋯ + θpxp

这里“线性”指对参数 θ 线性，不是对原始输入 x 画出来必须是直线。将 x²、x³ 看成新特征后，仍能用同样的优化方法。

两个原始特征、二次多项式可用 {1,x₁,x₂,x₁²,x₁x₂,x₂²}。包含全部不超过 p 次的项时，总项数（含常数）为组合数 C(d+p,p)。维度随 d 和 p 增长很快。

Lreg = (1/n)‖Xθ−y‖² + (λ/n)∑j=1dθj²
θ = (XᵀX + λD)⁻¹Xᵀy，D = diag(0,1,…,1)此处 d 表示设计矩阵中除截距外的特征数。常见约定不惩罚 θ₀；正则梯度为 (2λ/n)Dθ。

正则化惩罚大系数，限制模型复杂度；λ 太大可能欠拟合。它可能改善验证误差，但不会让已全局最优的无正则训练 MSE 再降低。缩放特征会改变系数和惩罚的相对大小，因此正则化时尤其要注意尺度。

3. 逻辑回归：预测为正类的概率

z = xᵀθ，p = σ(z) = 1/(1+e−z)
P(y | x) = py(1−p)1−y
L = −(1/n)∑i[yi ln pi + (1−yi)ln(1−pi)]
∇L = (1/n) Xᵀ(p − y)

它名字里有 Regression，但常用于分类。先计算概率，再按阈值决定类别。阈值为 0.5 时，边界对应 xᵀθ=0；加入多项式特征可以得到原空间中的非线性边界。

交叉熵来自最大化真实标签的似然。y=1 时损失为 −ln p；y=0 时为 −ln(1−p)。自信地预测错会受到很大惩罚；分类正确也不代表损失为 0。

INTERACTIVE 04 / SIGMOID & LOSS

“分对了”与“概率足够好”是两回事

固定真实标签 y=1。拖动模型得分 z 或分类阈值，观察概率、类别和损失。

严谨理解凸性：标准逻辑回归的交叉熵对参数是凸的，但“凸”本身不保证存在唯一的有限最小值。例如，无正则且数据完全线性可分时，参数可不断增大，损失趋近下确界。讲义 p.63 的“总有唯一最小值”需要额外条件。

4. 验证流程：别让答案提前泄漏

训练集：学习参数→验证集：选模型/超参数→测试集：最终评价

k、树深度、λ、学习率等属于超参数。反复依据测试集表现调整它们，相当于间接“学过”测试集，最终指标会过于乐观。

K-fold cross-validation：把可用于模型开发的数据分成 K 折，轮流用一折验证、其余训练，汇总各折结果。调参后可以在全部开发数据上重新拟合，最后只用保留的测试集评价。

归一化的正确顺序

① 切分数据 → ② 用训练集求 μ、σ → ③ 用同一组 μ、σ 变换训练、验证、测试集 → ④ 训练与评价。在交叉验证中，每一折也必须只在该折训练部分拟合预处理。

2. Bagging 与 Random Forest：减少方差

决策树对训练数据的小变化很敏感。Bagging 对原始 N 条训练记录进行有放回抽样 N 次，形成一个 bootstrap 数据集，再训练一棵树。重复多次，分类时投票，回归时平均。

有放回意味着一个数据集可能出现重复记录，也可能缺少某些原始记录。各棵树可独立训练，容易并行。

Random Forest = Bootstrap sampling + 每次分裂的随机特征子集

如果每棵树都能看到很强的同一个特征，它们的顶层分裂可能十分相似。随机森林在每个节点的分裂只考虑随机抽到的一部分特征，减少树之间的相关性，让平均更有效。

不要混淆：标准随机森林不是为整棵树永久固定一组特征。“树越多一定越过拟合”通常也不成立；单树深度、特征、数据与树间相关性都更值得分析。更多树仍会增加计算成本。

3. AdaBoost：提高被分错样本的权重

初始每条样本权重为 1/N。每轮训练一个弱分类器，用当前权重计算错误率，并决定这个分类器有多大的投票权。

εm = ∑iwi · 𝟙[hm(xi) ≠ yi]
αm = ½ ln[(1−εm) / εm]
wi ← wieαₘ（分错）；wi ← wie−αₘ（分对）
最后归一化：wi ← wi / ∑jwj

后续学习器更关注难分的样本。讲义通过按权重重新采样实现；也可以用支持样本权重的学习器。最终对各类别累加 α 加权投票，而不是简单数树的数量。

手算例题

若 ε=0.2，则 α=½ln4≈0.693。错分样本权重乘 2，正确样本乘 0.5，再统一归一化；两者的相对权重比放大 4 倍。

当 ε=0.5，α=0，没有正向投票贡献；ε>0.5 时 α 为负，需处理该弱分类器。ε=0 时公式出现无穷，实践中需停止或作数值保护。

4. Gradient Boosting：下一棵树学习残差

对于平方损失回归，可以从目标均值开始预测。每轮计算当前残差，训练一棵回归树预测它，再把预测残差的一部分加回原模型。

F₀(x) = mean(y)
rim = yi − Fm−1(xi)
hm ← 拟合 (xi, rim)
Fm(x) = Fm−1(x) + ηhm(x)
讲义例题 / p.40–41

一条记录真实值为 1400，当前预测 1000，因此残差 400。新树给它的预测残差是 350，η=0.1，则新预测为 1000+0.1×350=1035，新残差为 365。

注意：加的是“树预测的残差”，不是该样本的真实残差；否则测试时就需要知道真实答案。

一般的 Gradient Boosting 拟合的是损失对当前预测的负梯度。平方损失下它对应残差；分类时通常在分数空间迭代，再通过 sigmoid/softmax 得到概率，不能把所有损失都机械理解为 y−ŷ。

LECTURE 07 / DIMENSIONALITY REDUCTION

特征太多时，怎样只留下最重要的方向？

特征一多，数据就变得稀疏，距离失去区分度，模型容易过拟合，计算也更贵。本讲有两条路：特征选择直接删掉一部分原特征；特征提取用原特征造出更少的新特征。提取方法里，PCA、LDA 是线性的，t-SNE 是非线性的。

Curse of DimensionalityFeature SelectionPCALDAt-SNE

1. 维度灾难：为什么特征越多越麻烦

设 m 是数据点个数（“质量”），V 是特征张成的空间（“体积”）。维度每增加一维，体积成倍增长，而点数不变，所以高维数据很快变得非常稀疏。后果有三：计算成本升高；任何依赖统计显著性的方法都更难，过拟合风险变高（好点和噪声/离群点越来越难区分）；在低维里相似的点，在高维里可能不再相似。

Ld ≈ k / N　⇒　L ≈ (k / N)1/dN 个点均匀分布在 d 维单位立方体中；L 是包住某个点的 k 个最近邻所需的最小立方体边长。
讲义例题 / p.4

N = 1,000，k = 10，所以 k/N = 0.01。d = 2 时 L = 0.011/2 = 0.1；d = 3 时 0.215；d = 10 时 0.010.1 ≈ 0.631；d = 100 时 0.955；d = 1,000 时 0.995。

也就是说，10 维时为了“圈住”1% 的点，每条边要覆盖 63% 的范围；到 100 维，近邻立方体几乎就是整个单位立方体。所谓“最近邻”已经不近了，第 4 讲的 KNN 在高维里会因此失效。讲义 p.5 的直方图也显示：维度越高，两两距离越集中在同一个值附近，平均距离趋同。

2. 两类对策：特征选择 vs 特征提取

特征选择 Feature Selection特征提取 Feature Extraction
做法分析前删掉一部分原特征（或只保留一个子集）用原特征的组合生成新的“摘要”特征
常见手段按专家知识删无关特征（如生日与消费行为）；删可能带来伦理偏见的特征（如信用卡审批中的性取向、种族）；删方差很低的特征；两两相关性很高时删掉其一；按判别能力排序（决策树靠近根的特征更有用）PCA、LDA（线性组合）；t-SNE（非线性）。利用特征之间的相关性与判别能力，例如 2 维几乎无损地压到 1 维

缺点专家知识常常不明显；最小方差、相关系数等阈值难定新特征是组合，可解释性下降；会丢信息

3. PCA：沿方差最大的方向投影

PCA（Principal Component Analysis）是线性、无监督的：新特征是原特征的线性组合，相当于换一套坐标轴，完全不看类别标签。给定 X（n 个样本 × d 个特征），找矩阵 W（d × p），使 XW 成为 n × p 的新数据，p < d。

什么样的投影方向最好？讲义给了两个等价目标：让投影残差（点到直线的垂直距离）最小，或让投影后的点方差最大。后者更好推导。

预处理：先做均值中心化（不改变结果，只让数学更简单）。再除以标准差做标准化是可选的，但会改变结果——单位大的特征方差大，不标准化就会主导 PC1。

w1 = argmax‖w‖=1 (1/n)∑i(xiᵀw)² = argmax‖w‖=1 wᵀCXw，　CX = XᵀX / n
J(w) = wᵀCw / wᵀw　→　dJ/dw = 0　⇔　Cw = J(w)·wJ(w) 是 Rayleigh quotient。令导数为 0 得到特征值问题：w₁ 是协方差矩阵 CX 最大特征值对应的特征向量，投影后的方差就等于这个特征值。若用 CX = XᵀX（散度矩阵）而不除以 n，只改变特征值大小，不改变特征向量。

第 k 个主成分：先从 X 中减去前 k−1 个主成分方向上的分量，Xk = X − ∑s=1k−1 X wswsᵀ，再找使方差最大的单位向量。数学上它恰好是 CX 的第 k 大特征值对应的特征向量。所以“求所有主成分”= 对 CX 做特征分解，按特征值从大到小排序；各主成分两两正交。

保留几个主成分：解释方差比

Explained variance ratio of PCi = λi / ∑jλj选最小的 p，使前 p 个主成分合计解释的方差达到要求（如 90% 或 95%）。
讲义例题 / p.21–23

二维例子的特征值为 [0.22, 1.88]，归一化后为 [0.11, 0.89]：只用 PC1 就保留了 89% 的方差。IRIS 取 3 个特征时，三个主成分分别解释 92%、7%、1%；只用 PC1 保留 92%，用 PC1 + PC2 保留 99%。

补充手算 / 2 × 2 协方差矩阵

中心化后若 CX = [[2, 1], [1, 2]]，解 det(C − λI) = (2−λ)² − 1 = 0，得 λ₁ = 3、λ₂ = 1。λ = 3 对应 w₁ = (1, 1)/√2，λ = 1 对应 w₂ = (1, −1)/√2。PC1 的解释方差比为 3/(3+1) = 75%。两个特征正相关，所以最大方差方向是对角线 (1, 1)。

PCA 优点PCA 缺点
直观：利用相关特征和低方差特征的信息；能大幅减少数据量；提升算法速度、降低过拟合风险；可视化高维数据（EDA 时也常用）最根本的是丢信息；只能捕捉特征间的线性相关；假设方差大就重要（不一定）；不考虑类别标签
分类数据上的陷阱（p.25）：两类数据沿同一条长斜线分布、彼此平行。PCA 只看整体方差，PC1 沿长斜线方向，投影后两类完全重叠；真正能分开两类的是方差较小的 PC2。方差大 ≠ 对分类有用。

4. LDA：让同类更紧、异类更开

LDA（Linear Discriminant Analysis）同样是线性变换、同样输出投影矩阵 W，但它有监督，用到类别标签，并同时优化两个目标：投影后每个类内部的方差尽量小，类与类之间尽量分开。PCA 则是让整个数据集的方差最大。

SB = ∑i=1C n(i)(μ(i) − μ)(μ(i) − μ)ᵀ　（类间散度）
SW = ∑i=1C ∑x∈class i(x − μ(i))(x − μ(i))ᵀ　（类内散度）
J(w) = wᵀSBw / wᵀSWw　⇒　SW−1SBw = J(w)·wC 是类别数，n(i) 是第 i 类的样本数，μ(i) 是第 i 类的均值向量，μ 是全体均值。J(w) 是广义 Rayleigh quotient；最优投影方向是 SW−1SB 最大特征值对应的特征向量。

最多只有 C−1 个有用方向。SB 是 C 个秩不超过 1 的矩阵之和，而且各类均值与总体均值有约束（∑in(i)(μ(i) − μ) = 0），所以 rank(SB) ≤ C−1，最多 C−1 个非零特征值，其余 d−C+1 个为 0（实际计算中是极接近 0 的浮点数）。因此 LDA 的输出维度 p ≤ C−1；PCA 则可以选 1 到 d 任意值。

LDA 算法五步

  1. 计算总体均值 μ 和每类均值 μ(i)。
  2. 计算散度矩阵 SW、SB。
  3. 求 SW−1SB 的特征值与特征向量。
  4. 取特征值最大的 p 个特征向量（p ≤ C−1）组成 W。
  5. 投影：XW。
讲义例题 / IRIS p.38–39

3 类、3 个特征，特征值依次为 26.9、0.17、2.03×10−15：C−1 = 2 个非零，d−C+1 = 1 个为零。第一个方向解释 26.9/(26.9+0.17) ≈ 99.4%，所以 p = 1 已经足够。和 PCA 相比，LDA 的每一类更紧凑（SW 被最小化），类与类分得更开（SB 被最大化）。MNIST 有 10 类，所以 LDA 最多降到 9 维。

LDA 优点LDA 缺点
PCA 的直观扩展，有同样的好处（减少数据、降低过拟合、可视化）；利用类别标签，对有标签数据通常比 PCA 更合适同样丢信息、只能线性；假设每类是单峰高斯；假设均值是最有判别力的特征
LDA 失效的情形（p.41）：两类均值相同（μ1 = μ2）时 SB 接近 0，例如一类是双峰、另一类夹在中间，或两类均值相同只是方差不同；分布明显非高斯时也不可靠。LDA 只靠“均值之间的距离”来区分类别。

5. t-SNE：保住“谁是谁的邻居”

t-SNE 是非线性、无监督、迭代的方法：先随机给出低维表示 Y，再不断调整 Y，直到损失函数收敛。思路是把高维 X 和低维 Y 里的欧氏距离都换成“选谁当邻居”的概率，再让两组概率尽量相同。目标一句话：在 X 中相近的点，在 Y 中也要相近。

pj|i = exp(−‖xi − xj‖² / 2σi²) / ∑k≠i exp(−‖xi − xk‖² / 2σi²)
pij = (pj|i + pi|j) / 2n
qij = (1 + ‖yi − yj‖²)−1 / ∑k≠l(1 + ‖yk − yl‖²)−1
L = KL(P‖Q) = ∑i∑j pij log(pij / qij)
∂L/∂yi = 4∑j(pij − qij)(yi − yj)(1 + ‖yi − yj‖²)−1pj|i：以 xi 为中心放一个高斯，xi 选 xj 当邻居的概率。低维里改用自由度为 1 的 Student t 分布（尾巴更重，实践效果更好）。KL 散度衡量两个概率分布的差别。

基本算法（p.48）

  1. 输入：数据 X、迭代次数 T、学习率 η。
  2. 初始化：从 N(0, 10−4I) 随机采样 Y(0)；对所有 (xi, xj) 计算 pj|i 和 pij（P 只算一次）。
  3. 重复 T 次：计算所有 qij → 计算梯度 ∂L/∂yi → 更新 yi ← yi − η·∂L/∂yi。
  4. 返回 Y(T)。

σi 怎么选：按 xi 周围的密度设定——密度高用小 σi，密度低用大 σi，以此控制有多少个 xj 获得不可忽略的 pj|i。实际通过超参数 perplexity 求 σi：perplexity 越大，有效邻居越多；常用 5～50。讲义 p.52 展示了 perplexity 从 1 到 200 的效果，太小只看到碎片，太大则结构被抹平。

讲义例题 / p.44

以 x₃ 为中心放高斯：p4|3 = 0.84，p2|3 = 0.16，其他点约为 0。x₄ 离 x₃ 最近，所以最可能被选为邻居。

t-SNE 优点t-SNE 缺点
能处理非线性结构；数据可视化效果非常好在高维大数据上很慢（MNIST：PCA 4.9 秒，t-SNE 约 58 分钟）；非确定性，Y(0) 随机，每次结果不同，需要多跑几次；超参数多（perplexity、学习率、迭代次数、初始化）

实践组合（p.56–57）：先用 PCA 降到几十维，再跑 t-SNE，能大幅省时间（MNIST：PCA/28 + t-SNE 约 4.5 分钟）；也可以先用 LDA 降到 ≤ C−1 维（MNIST 为 1～9 维）再跑 t-SNE。

读 t-SNE 图要小心 补充：它保留的是“局部邻居关系”，图中簇与簇之间的距离、簇的大小一般没有可靠含义；它也不给出可直接套用到新样本的投影矩阵。所以 t-SNE 主要用于看图，而不是作为下游模型的特征变换。

Q1. 为什么 PCA 不一定适合有标签的分类数据？LDA 怎样解决这个问题？它又有什么限制？

Why may PCA be unsuitable for a labelled classification dataset, how does LDA address this, and what limits LDA?

参考要点 / Model answer

PCA 只最大化整体方差，忽略标签；方差最大的方向可能把两类混在一起（例如两类沿平行的长斜线分布）。LDA 使用标签，最大化类间散度、最小化类内散度，解 SW−1SB 的特征向量。限制：最多 C−1 个方向；假设单峰高斯、靠均值区分，均值相同时失效；仍是线性方法。

PCA maximizes the variance of the whole dataset and ignores class labels, so the direction of maximum variance can mix the classes. LDA uses the labels: it maximizes the between-class scatter and minimizes the within-class scatter by taking the top eigenvectors of SW−1SB. It yields at most C−1 directions, assumes unimodal Gaussian classes separated by their means, and is still linear.

Q2. 用“维度灾难”解释：为什么 KNN 在 1,000 维的数据上表现会变差？

Use the curse of dimensionality to explain why KNN performs poorly on 1,000-dimensional data.

参考要点 / Model answer

高维空间里点非常稀疏，两两距离趋于相同，“最近邻”和其他点的距离差不多。按 L ≈ (k/N)1/d，N = 1,000、k = 10、d = 1,000 时 L ≈ 0.995，近邻立方体几乎是整个空间，邻居不再“局部”，投票失去意义；还要更多数据才能有统计意义，容易过拟合。对策：特征选择或用 PCA 等降维后再做 KNN。

In high dimensions the data become very sparse and pairwise distances concentrate around the same value, so the nearest neighbours are hardly closer than any other point. With N = 1,000 and k = 10, the cube containing the 10-NN has side length (k/N)1/d ≈ 0.995 for d = 1,000, i.e. almost the whole space, so the neighbourhood is no longer local. Feature selection or dimensionality reduction (e.g. PCA) before KNN helps.

3. 基于内容（Content-based）：按物品特征找相似

直觉：用户给 v 打了高分，就推荐和 v 相似的物品（同类型电影、同歌手的歌、同主题文章）。前提是每个物品都有物品画像（item profile），即特征向量：电影的类型、导演、演员、年份；商品的类别、品牌、价格；文章的关键词或 tf-idf 向量。

sim(x, y) = cos θ = x · y / (‖x‖ ‖y‖)物品–物品相似度（p.26）：sim(Heat, Bad Boys) = 0.77，sim(Heat, Jarhead) = 0.33，sim(Heat, Clueless) = 0。缺点是需要一个参照物品：最近在看的、评分最高的，或正在浏览的。

用户画像：把评过的物品画像聚合起来

要算“用户–物品”相似度，用户画像必须和物品画像同形状：用户画像 = 用户评过的物品画像的某种聚合。

讲义例题 / 二值效用矩阵 p.29

Ruv ∈ {0, 1}（买了或看了 = 1），只有隐式“喜欢”。用户看过 5 部电影，其中 4 部是 comedy，则用户画像里 comedy = 4/5 = 0.8；action 2/5 = 0.4，romance 3/5 = 0.6，horror 0/5 = 0。就是对 5 个物品画像取平均。

讲义例题 / 实数评分 p.30–32

用户给 5 部电影的评分为 1.5、2.0、4.5、5.0、4.0。评分同时表达喜欢和不喜欢，所以先减去用户平均分 3.4，得到 −1.9、−1.4、1.1、1.6、0.6。这样能区分“宽松”的用户（多数打高分，3 分其实是低分）和“苛刻”的用户（3 分其实是高分）。

某个特征的权重 = 含该特征的电影的归一化评分平均。adventure 出现在第 1、2、5 部：(−1.9 − 1.4 + 0.6)/3 = −0.9；animation 出现在第 3、4、5 部：(1.1 + 1.6 + 0.6)/3 = 1.1。结论：这个用户喜欢动画，不喜欢冒险片。

然后用余弦相似度 sim(u, v) 比较用户画像与物品画像（两者量级不同，余弦只看方向），推荐相似度最高的物品。实践中还要：加入一些随机性保证多样性（否则 top-k 永远一样）；去掉用户已经评过的物品；更精细的聚合，例如忽略样本太少的特征（用户只看过一部喜剧）。

课堂小测（p.33）：要得到好的用户画像，需要保证的是“用户对同一类型评过足够多的电影”（答案 C）。某个类型只出现一两次，平均值就很不可靠。

4. 协同过滤（CF）：借别人的口味

协同过滤只用评分矩阵 R，不需要物品或用户特征：推荐口味相似的其他用户喜欢过的东西。两个视角：user-based（两个用户对相同物品评分相似，则用户相似）和 item-based（两个物品被用户们评分相似，则物品相似）。

为什么不能直接对评分向量算余弦？缺失值记为 0，会被当成“很差”；而所有评分都是正数，余弦只能表达“更相似 / 不那么相似”，表达不了“口味相反”。解决：对每一行（用户）只用他评过的物品求均值，减去均值做中心化，缺失值保持 0。这样 0 代表“平均”，低于平均的评分变成负数。中心化后的余弦相似度就是 Pearson 相关系数。

冷启动 = 新用户或新物品还没有（足够的）评分。基于内容：新用户没有画像，但新物品只要有特征就能被推荐。协同过滤：新用户找不到相似用户，新物品没有人评过，两边都受影响。缓解：给新用户先推热门或按人口属性/注册时选的兴趣推荐；新物品用内容特征（混合方法）；注册时让用户给几个物品打分；利用平台上的其他信息（位置、设备、来源页面等）。

Cold start means a new user or item has no (or too few) ratings. Content-based systems cannot build a profile for a new user, but can still recommend a new item from its features. Collaborative filtering suffers for both: a new user has no similar users and a new item has no ratings. Mitigations: recommend popular items or use demographic/onboarding preferences for new users, and use item features (a hybrid approach) for new items.

Q2. user-based CF 计算相似度前为什么要做均值中心化？中心化后的余弦相似度有什么名字？

Why is mean-centering applied before computing user similarities in user-based CF, and what is the cosine similarity of the centred vectors called?

参考要点 / Model answer

不中心化时缺失值 0 被当作最低分，且评分全为正，余弦无法表达“口味相反”。减去每个用户自己的平均分后，0 代表平均，低于平均为负，同时消除了打分松紧的差异。中心化后的余弦就是 Pearson 相关系数。

Without centring, missing values (0) act as very bad ratings and, since all ratings are positive, cosine similarity cannot express opposite tastes. Subtracting each user's mean rating makes 0 mean "average", turns below-average ratings negative, and removes differences between generous and strict raters. The cosine similarity of mean-centred vectors is the Pearson correlation coefficient.

2. 社区发现：Modularity 与 Louvain

社区没有严格定义。Newman 的说法：把网络自然地分成若干组，使组内边多、组间边少，但“多”和“少”本身有争议。听起来像聚类——是的，区别在于聚类看两两相似度，社区发现看连通程度。应用：社交群体、推荐系统、市场细分、异常检测。

Q = (1/2m) ∑v,w [ A[v, w] − kvkw / 2m ] · δ(cv, cw)，　Q ∈ [−½, 1]
等价的手算形式：Q = ∑c [ Lc/m − (Dc / 2m)² ]kv：与 v 相连的边权之和（度）；m：全部边权之和；δ = 1 当且仅当 v、w 在同一社区。Lc：社区 c 内部的边权和；Dc：社区 c 内节点的度之和。Q 衡量“社区内部的边”比随机情况下多出多少。求 Q 的最大值是 NP-hard，所以实际算法都是启发式。
讲义例题 / p.22 手算验证

4 个节点，边 0–1、1–2、1–3、2–3，m = 4，度为 k = (1, 3, 2, 2)。

每个点自成一个社区：没有社区内部的边，Q = −∑k²/(2m)² = −(1+9+4+4)/64 ≈ −0.28。

把 0 并入 1 的社区：{0,1} 内有 1 条边，度和为 4：1/4 − (4/8)² = 0；{2}、{3} 各贡献 −(2/8)² = −1/16。Q = −0.125，比 −0.28 好，所以移动。

最终 {0,1}、{2,3}：两边各为 1/4 − (4/8)² = 0，Q = 0.0。

Louvain 算法

  1. 初始化：每个节点自成一个社区。
  2. 阶段 1 · 模块度优化：依次检查每个节点 v，把它移到某个相邻社区能否提高 Q；移到使 Q 提高最多的社区（若都不提高则不动）。节点的归属可以在后续迭代中再变。
  3. 阶段 2 · 图聚合：把每个社区缩成一个新节点；社区内部的边变成新节点上的自环，社区之间的边权相加成为新边权。
  4. 重复两个阶段，直到社区不再变化。

它是启发式：只在局部优化 Q，不保证全局最优，但实践中常优于其他方法。ΔQ 可以只根据局部变化计算，不必每次重算整张图的 Q。

3. 按“切开”来找社区：Girvan–Newman 与 Karger

Girvan–Newman：反复删掉“桥”

这是分裂式层次方法：从整张图出发，反复删边，直到分成两个子社区，必要时对子社区递归。删哪条边由边介数中心性决定：所有节点对的最短路径中，经过该边的比例之和。连接两个社区的“桥”上，最短路径特别多。

cB(e) = ∑v,w∈V σ(v, w | e) / σ(v, w)σ(v, w)：v 到 w 的最短路径条数；σ(v, w | e)：其中经过边 e 的条数。讲义中的数值还除以了节点对总数 n(n−1)/2。
讲义例题 / p.27

两个三角形 {0,1,2}、{3,4,5} 由边 (2,3) 相连，6 个节点共 15 个节点对。左右两侧之间的 3×3 = 9 对的最短路径都经过 (2,3)，所以 cB(2,3) = 9/15 = 0.600；(0,2) 承担 0 到 {2,3,4,5} 的 4 对，4/15 = 0.267；(0,1) 只承担 0–1 这一对，1/15 = 0.067。删掉 (2,3)，图分成两个三角形。

算法

  1. 重复：对所有边计算 cB(e)，删掉 cB 最大的边；直到图分成 2 个连通分量。
  2. 对每个新分量递归，直到分量只剩 1 个节点（或按用户设定提前停止）。

代价：每轮都要解全源最短路径（APSP），复杂度取决于图的类型（有向/无向、是否有环、是否有负权）。

课堂讨论（p.40）：如果有好几条边的 cB 并列最大怎么办？讲义没有给标准答案。常见做法：一次删一条（任选或按固定规则），删完重新计算 cB，因为删一条边会改变其他边的介数；一次全删更快，但可能把图切得过碎。

Karger 最小割：随机收缩

最小割问题：把图切成两部分，使两部分之间的边数最少。Karger 算法是随机方法，适用于无向、正权图（无权图视为权重 1）。

  1. 当剩余节点数 |V| > 2：随机选一条剩余的边 e = (v, u)，把 v 和 u 收缩成一个新节点。
  2. 更新 v、u 与邻居之间的边（保留平行边），删掉自环。
  3. 只剩 2 个节点时，它们之间的边就是找到的割。基本运行时间 O(|V|²)。

直觉：最小割上的边很少，所以被随机选中、被提前收缩掉的概率较低。讲义例子 p.33–34：8 个节点、14 条边，依次收缩 (B,F)、(G,H)、(D,GH)…，平行边越多被选中概率越大（如 (AE, BF) 有 4 条平行边，概率 4/9），最后得到 |Min-Cut| = 2。

平均度 = 2m/n，|Min-Cut| ≤ 最小度 ≤ 2m/n　⇒　P(随机选中的边在最小割上) ≤ (2m/n)/m = 2/n
P(success) ≥ (1 − 2/n)(1 − 2/(n−1))⋯(1 − 2/3) = 2 / (n(n−1)) = 1 / C(n, 2)
运行 k = C(n, 2)·ln n 次取最小：P(failure) ≤ (1 − 1/C(n,2))C(n,2)·ln n ≤ (1/e)ln n = 1/n每轮 O(n²)，共 O(n²log n) 轮 ⇒ 总时间 O(n⁴ log n)，以很高概率得到最小割。例如 n = 8 时单次成功率下界只有 1/28 ≈ 3.6%。

一张图通常有多个最小割，选哪个与应用有关，例如偏好两部分大小相近的割，或忽略某一部分小于阈值的割。

Q1. 比较 Louvain 与 Girvan–Newman 两种社区发现算法的思路与代价。

Compare the Louvain and Girvan–Newman community-detection algorithms in terms of approach and cost.

参考要点 / Model answer

Louvain 是自底向上的：每个点先自成社区，反复把节点移到使 modularity 增加最多的相邻社区，再把社区聚合成新节点，直到不变；启发式、局部最优、速度快。Girvan–Newman 是自顶向下（分裂式）的：反复删除边介数最大的边，直到图分成两部分，再递归；每轮都要算全源最短路径，代价高，适合小图。

Louvain is bottom-up: every node starts as its own community, nodes are greedily moved to the neighbouring community that most increases modularity, and communities are then aggregated into super-nodes until nothing changes. It is a fast local heuristic without a global guarantee. Girvan–Newman is top-down (divisive): it repeatedly removes the edge with the highest edge betweenness until the graph splits, then recurses. Each round needs all-pairs shortest paths, so it is expensive.

Q2. 为什么 PageRank 要引入随机跳转（damping factor α）？

Why does PageRank include random jumps with a damping factor α?

参考要点 / Model answer

基本的 PR = M·PR 需要图强连通。真实网页图有没有出链的悬挂节点和走不出去的区域，幂迭代会失效或把分数集中到陷阱里。随机冲浪模型以概率 α 沿链接走、以 1 − α 随机跳到任意页面，相当于加了虚拟边，使图全连通、保证收敛，并让每个页面至少得到 (1 − α)/|V|。

The basic formulation PR = M·PR requires a strongly connected graph, but the web graph has dangling nodes and traps, so power iteration fails. In the random surfer model the surfer follows a link with probability α and jumps to a random page with probability 1 − α. The jumps act as virtual edges, making the graph fully connected so power iteration converges, and every page gets at least (1 − α)/|V|.

4. AR(p)：用自己的过去预测未来

xt = c + φ1xt−1 + φ2xt−2 + ⋯ + φpxt−p + εt = c + ∑i=1p φixt−i + εt线性：当前值是前 p 个值的线性组合；自回归：用自己的过去观测预测自己；由滞后阶数 p 完全确定。c 允许非零均值；εt 是创新（innovation）或冲击（shock），包含所有无法从过去预测的信息。看起来就是线性回归——正是如此。
假设含义怎么检查
线性依赖当前值可以用过去值的线性组合描述，每个滞后项按固定系数贡献拟合前通常无法断言，常靠可视化
（弱）平稳均值恒定 E[xt] = μ；方差有限且恒定 Var(xt) = σ²；自协方差只与间隔有关 Cov(xt, xt+h) = γ(h)，与发生在何时无关可视化 + 正式检验（ADF、KPSS）
白噪声冲击E[εt] = 0，Var[εt] = σε²，Cov(εt, εt−k) = 0（k ≠ 0）；常进一步假设 i.i.d. 或 N(0, σ²)拟合之后检查残差
稳定性过去观测与冲击的影响必须随时间衰减，例如 AR(1) 要求 |φ| < 1；这是平稳的必要条件看估计出的系数

平稳意味着：没有趋势、没有季节性（均值不恒定）、没有结构性断点、方差不变。不满足时可以只取一段序列，或先去趋势（detrending）等。

拟合：把序列变成回归问题

可选方法有普通最小二乘（OLS，“当成线性回归来解”）、Yule-Walker、Burg、条件/精确 MLE，它们在目标、稳定性与偏差的权衡、计算量与样本敏感度上不同。OLS 的关键是构造滞后特征矩阵：k 个观测、阶数 p，可得到 k − p 个训练样本，每个样本有 1（截距）+ p 个特征。

5. MA(q)：用过去的冲击解释现在

xt = μ + εt + θ1εt−1 + θ2εt−2 + ⋯ + θqεt−q = μ + εt + ∑i=1q θiεt−iμ 是过程均值；当前值是过去 q 个随机冲击的线性组合。关键区别：AR 用过去的观测，MA 用过去的冲击，而冲击无法直接观测。系数可以为负，绝对值也可能大于 1。
讲义例题 / p.45

MA(3)：xt = 100 + εt + 0.5εt−1 + 0.3εt−2 + 0.1εt−3。若 t 时刻冲击 εt = 10，它对 xt、xt+1、xt+2、xt+3 的影响依次为 10、5、3、1，之后为 0。冲击“走完”有限个时刻就消失：每个冲击都有有限寿命。AR 是自回归的，影响原则上无限延续；MA 不是。

假设与 AR 很像：线性依赖、均值恒定、白噪声冲击、（弱）平稳、规则采样；新增的是冲击影响有有限时间范围；非必需但常见的是可逆性（直觉：系数有唯一解）。可逆时，MA(q) 等价于 AR(∞)。

选 AR 还是 MA？冲击的后果比较短暂（如临时供应中断）用 MA(q)；变化更持久（原则上观测有无限影响）用 AR(p)。现实序列往往两种机制都有 → ARMA(p, q)。

拟合：最大似然

可用 MLE、条件平方和（CSS）、基于矩/ACF 的方法。MLE 的思路：对给定参数，算出观测数据出现的概率（似然），选使似然最大的参数。未知参数 θ = (μ, σε², θ1, …, θq)ᵀ。正态冲击不是核心假设，但要算似然必须假设一个分布，常用 εt ~ i.i.d. N(0, σε²)。

ℓ(θ) = −(T/2)log(2π) − (T/2)log σε² − (1/2σε²) ∑t=1T ε̂t²
ε̂t = xt − μ − ∑i=1q θiε̂t−i课堂小测：μ 和 θ 在哪里？它们藏在 ε̂t 里，而 ε̂t 又递归地依赖前面的 ε̂（也就依赖 μ 和 θ），所以不能像线性回归那样直接令 ∂ℓ/∂μ = ∂ℓ/∂θ = 0 解出来。

实际做法：先令 ∂ℓ/∂σε² = 0，得到解析解 σ̂ε² = (1/T)∑ε̂t²；代回似然得到简化的剖面似然（profile likelihood）；再用数值优化估计 μ 和 θ。所以拟合 MA 比拟合 AR 复杂得多。

讲义例题 / p.50–51

网店一年的日订单量（由 MA(3) 生成：μ = 1000，θ = 0.80、0.50、0.25，ε ~ N(0, 40²)）。用最后 31 天测试，估计得 μ̂ = 998，θ̂ = 0.90、0.57、0.18，σ̂ = 37.2。预测超过 q 步之后，模型只会给出估计的均值，因为未来的冲击未知、期望为 0。

6. 扩展：ARMA、ARIMA、SARIMA

ARMA(p, q)：xt = c + ∑i=1p φixt−i + ∑i=1q θiεt−i + εt
ARIMA(p, d, q)：对差分序列 x′t = xt − xt−1（共做 d 次）拟合 ARMA
SARIMA(p, d, q)(P, D, Q)s：再加季节差分 x′t = xt − xt−s 以及季节 AR、MA 项

AR、MA、ARMA 都要求序列围绕一个固定均值波动（弱平稳的条件之一），遇到向上或向下漂移（趋势）时表现很差。ARIMA 里的 “I” 是 integrated：不直接拟合观测值，而是拟合差分。

讲义例题 / 差分 p.55–56

(10, 12, 14, 16, 18) 有明显上升趋势，一次差分得 (2, 2, 2, 2)，平稳了，所以 d = 1。(1, 4, 9, 16, 25, 36) 一次差分得 (3, 5, 7, 9, 11)，仍有趋势；再差分得 (2, 2, 2, 2)，所以 d = 2。最常见 d = 0（就是 ARMA）或 d = 1，偶尔 d = 2。季节差分的例子：每日数据有每周规律时 s = 7。

模型能处理不能处理
AR / MA / ARMA平稳序列：围绕固定均值、方差恒定趋势、季节性、结构性断点、方差变化
ARIMA均值上的趋势（通过差分）方差变化（仍假设 Var(xt) = σ²）、季节性、结构性断点
SARIMA再加上稳定的季节模式方差变化、结构性断点；季节模式必须相当稳定，通常需要大量数据

总结：经典统计模型是专为时间序列设计、定义清楚的模型，可解释性高；通常不适合长期预测；必须认真对待假设：拟合前做 EDA（平稳性、趋势、季节性/周期、状态、断点），拟合后还要检查（例如残差是否为白噪声）。

7. 简答练习 · Short answer

Q1. 什么是弱平稳？为什么 AR、MA 模型需要它？序列有线性趋势时怎么办？

What is weak stationarity, why do AR and MA models need it, and what can be done if the series has a linear trend?

参考要点 / Model answer

弱平稳：均值恒定、方差有限且恒定、自协方差只依赖时间间隔 h。AR/MA 用固定系数描述“过去如何影响现在”，这种关系必须不随时间改变，模型才有意义、预测才稳定；趋势、季节性、断点、方差变化都会破坏它。有线性趋势时做一次差分（ARIMA，d = 1），或先去趋势再建模。

A weakly stationary series has a constant mean, a constant finite variance, and an autocovariance that depends only on the lag h. AR and MA models describe the effect of the past with fixed coefficients, which only makes sense if these statistical properties do not change over time; trends, seasonality, structural breaks and changing variance violate this. For a linear trend, difference the series once (ARIMA with d = 1) or detrend it before fitting.

Q2. 比较 AR(p) 与 MA(q)：各自依赖什么、冲击的影响持续多久、哪个更难拟合，为什么？

Compare AR(p) and MA(q): what each depends on, how long a shock's effect lasts, and which is harder to fit and why.

参考要点 / Model answer

AR(p) 依赖过去 p 个观测；冲击通过自回归一直传递，影响原则上无限（但在稳定条件下逐渐衰减）；可以用滞后特征 + OLS 直接拟合。MA(q) 依赖过去 q 个冲击；冲击只影响接下来 q 个时刻，寿命有限；冲击不可观测，估计值 ε̂t 递归依赖参数，只能用 MLE + 数值优化，所以更难拟合；预测超过 q 步后只剩均值。

AR(p) uses the past p observations, so a shock propagates through the autoregression and in principle has an infinite (though decaying) effect; it can be fitted directly with lag features and OLS. MA(q) uses the past q shocks, so a shock only affects the next q observations. Because shocks are not observed and the implied shocks depend recursively on the parameters, MA models must be fitted by maximum likelihood with numerical optimization, which is harder; beyond q steps an MA forecast is just the mean.

2. 采样：怎样拿到有代表性的样本

采样是从总体中选出成员做统计分析（比如不可能调查所有 HDB 居民）。在数据流中，总体就是源源不断的数据，时间和资源都不允许看每一条，核心难题是样本要有代表性。

朴素采样为什么会错

讲义例题 / p.15–16

数据流是搜索查询 (user, query, time)，目标：普通用户过去 24 小时里重复（这里是两次）提交的查询占多少。只允许存 10% 的元组。朴素做法：每来一条，以 1/10 的概率保存。

设 s = 只提交过一次的查询数，d = 提交过两次的查询数。正确答案是 d / (s + d)。在样本里：一个两次的查询，两条都被抽中的概率 (1/10)² → 期望 d/100 个仍显示“两次”；恰好抽中一条的概率 2·(1/10)(9/10) → 18d/100 个被误认为“一次”；只出现一次的查询有 s/10 个被抽中。

样本估计 = (d/100) / (d/100 + 18d/100 + s/10) = d / (10s + 19d)　≠　d / (s + d)

例如 s = d 时，真实比例是 1/2，样本估计却只有 1/29 ≈ 3.4%。问题在于按元组随机抽，把同一个用户的查询拆散了。

按“键”以给定比例采样

元组有 n 个分量，选其中一部分作为键，按键决定去留。这个例子里键 = user：只考虑 10% 的用户，但保留他们的全部查询，“提交两次”的结构就不会被破坏。键怎么选取决于分析目标。

要取 a/b 比例的键：哈希函数 h 把键映射到 b 个桶 1..b；新元组到达时，若 h(key) ≤ a（a ≤ b）就放进样本同一个键总是哈希到同一个桶，所以一个用户要么全部被保留，要么全部被丢弃。

固定大小的样本：Reservoir Sampling

目标：在任意时刻维护一个大小为 B 的均匀随机样本（每个已到达元素被选中的概率相同），可用来近似均值、方差、中位数等。

  1. 第 t 个元素 at 到达，若 t ≤ B：直接放入水库。
  2. 若 t > B：以概率 B/t 接纳 at，并替换水库中随机的一个元素；否则丢弃。

结论：任何时刻 t，每个已到达的元素都以概率 B/t 在水库里。

P(ai 在水库中) = (B/i)·(1 − 1/(i+1))·(1 − 1/(i+2))⋯(1 − 1/t) = (B/i)·(i/t) = B/t第一项：ai 被放进水库的概率。之后每一步 j，某个特定元素被替换的概率是 (B/j)·(1/B) = 1/j，所以“没被替换”的概率是 1 − 1/j = (j−1)/j；连乘时分子分母逐项相消，只剩 i/t。i = t 时就是算法直接给的 B/t。
讲义例题 / B = 3，p.19–24

流：A, B, C, A, C, B, B, A, C。t = 1～3 直接填满水库 [A, B, C]。t = 4：以 3/4 的概率接纳，结果接纳了 A，随机替换第 3 格 → [A, B, A]。t = 5：3/5，接纳 C，替换第 2 格 → [A, C, A]。t = 6：3/6，这次丢弃 B。t = 7：3/7，接纳 B，替换第 3 格 → [A, C, B]。

3. 过滤：Bloom Filter

只接受满足条件的元素。条件若是元素自身的属性（关键词多于 2 个、状态码有效）很简单；难的是条件涉及在一个很大的集合 S 中查成员：只接受白名单发件人的邮件（垃圾邮件过滤）、只统计访问特定网站集合的访问、只处理选定用户组的推文。

直接建哈希表需要把整个 S 存下来，内存不够怎么办？只存一个位数组：

  1. 位数组 B 有 n 位，初始全为 0；选哈希函数 h(key) ∈ [1, n]。
  2. 对 S 中每个键 s，令 B[h(s)] = 1。
  3. 新元素的键为 k：若 B[h(k)] = 1 则接受，否则丢弃。

问题：假阳性。a ∈ S、b ∉ S，但 h(a) = h(b)，b 也被接受。没有假阴性：S 里的键对应的位一定是 1（课堂小测 p.30，答案 A）。

插入一个键后某一位仍为 0 的概率：1 − 1/|B|
插入全部 |S| 个键后仍为 0：(1 − 1/|B|)|S| = (1 − 1/|B|)|B|·|S|/|B| ≈ e−|S|/|B|
假阳性率（一个哈希函数）≈ 1 − e−|S|/|B|用到 ep = [limn→∞(1 + 1/n)n]p。例：|S| = 10⁹ 个白名单邮箱，|B| = 8·10⁹ 位（1 GB 内存），|S|/|B| = 1/8，假阳性率 1 − e−1/8 ≈ 11.75%。

Bloom filter 在不增大 B 的前提下降低误判：用 m 个相互独立的哈希函数 h1…hm，插入时把 m 个位置都设为 1；查询时m 个位置全为 1 才接受。

假阳性率 ≈ (1 − e−m|S|/|B|)m　　最优 mbest = (|B| / |S|)·ln 2m 越大，需要同时为 1 的位越多（降低误判）；但数组里的 1 也越多（提高误判），所以存在全局最优。|S|/|B| = 1/8 时 mbest = 8 ln 2 ≈ 5.5，取 6，假阳性率 ≈ 2.2%。时间复杂度 O(m)，空间复杂度 O(|B|)。

课堂讨论（p.31）· 白名单 vs 黑名单：Bloom filter 只会“多接受”，不会“漏掉”。当白名单用（在 S 中才放行）时，少数不在名单上的发件人会混进来，但名单上的人绝不会被误拦；当黑名单用（在 S 中就拦截）时，所有黑名单项都一定会被拦住，但少数无辜的项会被误拦。哪种更合适取决于哪类错误代价更高。

4. 计数：Flajolet–Martin 估计不同元素个数

应用：独立访客数（按用户 ID 或 IP 地址）、大文档中不同单词的个数。直接做法是维护一个集合 S，答案是 |S|，但 S 可能非常大。Flajolet–Martin 用很小的内存给出近似估计：无偏地估计不同元素个数，接受误差但尽量降低其概率。

  1. 选哈希函数，把 n 个可能的元素映射到至少 log₂n 位（例如 2³² 个 IPv4 地址 → 至少 32 位）。
  2. 对流中的每个元素 s：算 h(s)；r(s) = h(s) 末尾 0 的个数；维护最大值 R = max r(s)。
  3. 返回估计值 2R。

重复出现的元素哈希值相同，不会改变 R，所以它天然只数“不同”的元素。讲义 p.42：一串 IP 地址中最大尾零数 R = 3，估计不同元素约 2³ = 8 个。

P(h(a) 至少 k 个尾零) = (1/2)k = 2−k
m 个不同元素时 P(R ≥ k) = 1 − (1 − 2−k)m ≈ 1 − e−m/2k
2k ≪ m ⇒ P(R ≥ k) ≈ 1；　2k ≫ m ⇒ P(R ≥ k) ≈ m/2k ≈ 0第二种情况用了 ex ≈ 1 + x（x ≪ 1）。所以 R 很可能落在 log₂m 附近，2R 与 m 在同一数量级。直觉：不同元素越多，不同的哈希值越多，出现“罕见”的位模式（很多尾零）的可能越大。
课堂小测 / 三枚硬币

有人说他同时抛三枚公平硬币，第 k 次才得到三个正面。哪个 k 最可信？每次成功概率 1/8，大约 8 次能见到一次，所以 k = 10 最可信（答案 B）。这正是 FM 的逻辑反过来用：见到 R 个尾零，大约已经有 2R 个不同元素。

基本算法的问题：估计值永远是 2 的幂；R 只差 1，估计就翻倍或减半。改进：用 p·q 个哈希函数得到 p·q 个估计；分成 p 组、每组 q 个；每组取中位数，再对 p 个中位数取平均。为什么不直接全取平均或全取中位数？平均值会被偏大的估计拉高（某个 R 偏大，2R 就大得多）；中位数仍然只能是 2 的幂。先中位数后平均，两者兼顾。

Q1. 为什么 Bloom filter 不会产生假阴性，却会产生假阳性？怎样在不增加内存的情况下降低假阳性率？

Why can a Bloom filter produce false positives but never false negatives, and how can the false positive rate be reduced without more memory?

参考要点 / Model answer

S 中每个键插入时都把自己的 m 个位置设为 1，位只会从 0 变 1、不会变回 0，所以查询 S 中的键时这些位一定全是 1：没有假阴性。不在 S 中的键，它的 m 个位置可能恰好都被别的键设成了 1：假阳性。不加内存时，选合适的哈希函数个数 m（最优约为 (|B|/|S|) ln 2），误判率 ≈ (1 − e−m|S|/|B|)m。

Every key in S sets its m bits to 1 when inserted and bits are never reset, so a lookup of a key in S always finds all its bits set: no false negatives. A key not in S may hash to positions that other keys have already set, which is a false positive. Without enlarging the bit array, use an appropriate number of hash functions, m ≈ (|B|/|S|) ln 2, giving a false positive rate of about (1 − e−m|S|/|B|)m.

Q2. 说明 reservoir sampling 的算法，并解释为什么每个元素被保留的概率都是 B/t。

Describe reservoir sampling and explain why every element is kept with probability B/t.

参考要点 / Model answer

前 B 个元素直接放入；第 t（> B）个元素以 B/t 的概率接纳，并随机替换水库中的一个。元素 ai 被放入的概率是 B/i；之后第 j 步它被替换的概率是 (B/j)(1/B) = 1/j，所以保留到 t 的概率是 (B/i)·∏j=i+1t(j−1)/j = (B/i)(i/t) = B/t，与 i 无关，样本是均匀的。

The first B elements are added directly; element t > B is accepted with probability B/t and replaces a uniformly random element of the reservoir. Element ai enters with probability B/i, and at each later step j it is replaced with probability (B/j)(1/B) = 1/j. Hence it survives to time t with probability (B/i)·∏j=i+1t(j−1)/j = (B/i)(i/t) = B/t, independent of i, so the sample is uniform.
