预处理 Q01 · 4 min

属性类型与编码

Classify the attributes and choose an encoding for an unordered category.

判断属性类型：学生编号、满意度（低/中/高）、摄氏温度、文件大小（字节）。对无序类别“浏览器类型”直接编码为 1、2、3 后用于欧氏距离，有何问题？

展开答案与解析 / Show solution
学生编号：nominal；满意度：ordinal；摄氏温度：interval；文件大小：ratio。无序类别的数字编码会引入不存在的大小和间距，可用 one-hot。Ordinal 编码也不自动意味着等级之间距离相等。
易错点 / Watch out：数字外观不等于数值属性；区间尺度的零点可以任意。
预处理 Q02 · 4 min

标准化与数据泄漏

Compute a z-score and fix a preprocessing pipeline.

训练集某特征均值 μ=20、标准差 σ=5。测试点 x=32 的 z-score 是多少？有人先用全体数据求均值与标准差，再拆分训练/测试集，是否合适？

展开答案与解析 / Show solution
z=(32−20)/5=2.4。应先划分数据，再只用训练集拟合标准化参数，固定后变换验证/测试集。交叉验证中也要在每个训练折内部拟合预处理。
易错点 / Watch out：即使没有使用测试标签，使用测试分布拟合预处理仍会泄漏信息。
聚类 Q03 · 6 min

K-means 一轮更新

Run one assignment/update iteration and compute SSE.

一维点 {0,2,3,10,12}，k=2，初始中心为 0、10。用欧氏距离分配，更新中心，并计算更新后的 SSE；下一轮分配会变吗？

展开答案与解析 / Show solution
分簇 C₁={0,2,3}，C₂={10,12}；新中心 5/3、11。SSE=(25+1+16)/9+1+1=20/3≈6.667。新分界点为 (5/3+11)/2=19/3≈6.333，分配不变，已达到稳定分配。
易错点 / Watch out：SSE 使用平方距离；计算时明确用更新前还是更新后的中心。
聚类 Q04 · 6 min

DBSCAN 的三种点

Identify core, border, and noise points.

一维点 A=0、B=0.4、C=0.8、D=1.6、E=4。ε=0.9，MinPts=3；邻域含自身，距离 ≤ε 算邻居。列出各点邻域大小、点类型、最终簇。

展开答案与解析 / Show solution
邻域大小 A:3，B:3，C:4，D:2，E:1。A/B/C 是 core，D 是 border（在核心点 C 的邻域内），E 是 noise。唯一簇为 {A,B,C,D}。
易错点 / Watch out：边界点不必达到 MinPts；本题已规定计入自身，不要混用另一种约定。
聚类 Q05 · 6 min

AGNES：single vs complete

Build two dendrograms using different linkages.

一维点 A=0、B=2、C=5、D=9。分别用 single linkage 和 complete linkage，写出每次合并及其高度。

展开答案与解析 / Show solution
两者先在距离 2 合并 A、B。Single：距离 3 合并 {A,B} 与 C，再在 4 合并 D。Complete：{A,B} 到 C 的距离是 5，而 C 到 D 是 4，因此第二步在 4 合并 C、D，最后在 9 合并 {A,B} 与 {C,D}。
易错点 / Watch out：Single 取跨簇最小距离；complete 取跨簇最大距离。每次合并后重算簇间距离。
关联规则 Q06 · 5 min

Support / confidence / lift

Compute rule metrics in both directions.

200 笔交易中，A 出现 80 次，B 出现 150 次，A、B 同时出现 50 次。计算 A→B 的 support、confidence、lift，以及 B→A 的 confidence。

展开答案与解析 / Show solution
support=50/200=0.25；confidence(A→B)=50/80=0.625；lift=0.625/(150/200)=5/6≈0.833；confidence(B→A)=50/150=1/3。Lift<1，说明本数据中 A 的出现与 B 呈负向关联，不能由 62.5% 的置信度断言正向关联。
易错点 / Watch out：规则的 support 是交集占全部交易的比例；confidence 的分母是前件。
关联规则 Q07 · 4 min

Apriori 候选剪枝

Generate and prune 3-item candidates.

频繁二项集 L₂={AB, AC, AD, BC, BD}，CD 不频繁。按字母序连接与剪枝，哪些三项候选保留？是否可以直接说它们频繁？

展开答案与解析 / Show solution
连接可产生 ABC、ABD、ACD；ACD 因 CD 不频繁被剪掉。最终保留 ABC、ABD。BCD 同样因 CD 不频繁不可能频繁。保留下来的候选还必须扫描交易、计算支持度，才能确定是否频繁。
易错点 / Watch out：所有子集频繁只是必要条件，不是充分条件。
关联规则 Q08 · 6 min

Closed 与 maximal

Find all closed and maximal frequent itemsets.

仅有项目 A、B、C。交易为 ABC、ABC、AB、A，minsup=50%。列出所有非空频繁项集、闭合频繁项集和最大频繁项集。

展开答案与解析 / Show solution
支持计数：A=4，B=3，C=2，AB=3，AC=2，BC=2，ABC=2；七个都频繁。Closed：A、AB、ABC；maximal：仅 ABC。B 与其真超集 AB 支持度相同，故不 closed；AC、BC、C 与 ABC 支持度相同。
易错点 / Watch out：Closed：没有相同支持度的真超集。Maximal：没有任何频繁真超集。
分类 Q09 · 5 min

混淆矩阵与 F1

Compute evaluation metrics with the stated positive class.

以“违约”为正类：TP=36、FP=12、FN=24、TN=128。计算 accuracy、precision、recall、F1；总预测为负的基线模型 accuracy 是多少？

展开答案与解析 / Show solution
总数 200。Accuracy=164/200=0.82；precision=36/48=0.75；recall=36/60=0.60；F1=2TP/(2TP+FP+FN)=72/108=2/3≈0.667。全预测负：accuracy=140/200=0.70，但正类 recall=0。
易错点 / Watch out：TN 不是实际负类总数；实际负类=TN+FP。
分类 Q10 · 8 min

决策树分裂

Compare splits using information gain and Gini decrease.

父节点有 4 正 4 负。分裂 A：左 3 正 1 负，右 1 正 3 负；分裂 B：左 2 正 0 负，右 2 正 4 负。分别算信息增益与 Gini 降低量，选哪个？log 以 2 为底。

展开答案与解析 / Show solution
父熵=1。A：加权子熵 H(3/4)=0.8113，IG=0.1887。B：子熵=(2/8)×0+(6/8)×H(1/3)=0.6887，IG=0.3113，选 B。父 Gini=0.5；A 子 Gini=0.375，降低 0.125；B 子 Gini=(6/8)×4/9=1/3，降低 1/6，仍选 B。
易错点 / Watch out：对子节点不纯度按样本数加权，不能直接求简单平均。
分类 Q11 · 4 min

KNN 与尺度

Predict with k=1 and k=3; explain scaling.

到查询点最近的三条记录依次为：距离 0.2 标签 +；距离 0.5 标签 −；距离 0.8 标签 −。用不加权投票预测 k=1 与 k=3。若特征中收入按元、年龄按年计，为什么应考虑标准化？

展开答案与解析 / Show solution
1-NN 为 +；3-NN 为 −。距离投票只按数量，不按距离加权。量纲和数值范围会改变欧氏距离各项的贡献，收入可能支配距离；可只用训练集拟合标准化参数。
易错点 / Watch out：题目若没有说加权投票，不要自行使用 1/d 权重。
回归与验证 Q12 · 6 min

线性回归梯度

Take one batch gradient descent step.

数据 (x,y)={(1,2),(2,4)}，模型 ŷ=wx+b，J=(1/2n)Σ(ŷ−y)²。初始 w=b=0，η=0.1；同步更新一次 w、b，并求更新后的 J。

展开答案与解析 / Show solution
∂J/∂w=(−2×1−4×2)/2=−5；∂J/∂b=(−2−4)/2=−3。w新=0.5，b新=0.3。新预测 0.8、1.3；J=(1.44+7.29)/4=2.1825。
易错点 / Watch out：必须根据同一组旧参数求全部梯度；损失中的 1/2n 决定是否出现系数 2。
回归与验证 Q13 · 6 min

Logistic：概率、损失与梯度

Compute probability, cross-entropy, and one SGD step.

单样本 x=2、y=1，模型 p=σ(wx+b)，初始 w=0.5、b=−1。求 p、二元交叉熵（自然对数），阈值 0.6 下的预测；再用 η=0.1 更新一次。

展开答案与解析 / Show solution
z=0，p=0.5；loss=−ln(0.5)=0.6931。阈值 0.6 下预测为 0。∂L/∂w=(p−y)x=−1，∂L/∂b=p−y=−0.5，因此 w新=0.6，b新=−0.95。新 z=0.25，p≈0.5622，仍未达到阈值。
易错点 / Watch out：概率、离散预测和损失是三件事；损失不依赖你选择的分类阈值。
回归与验证 Q14 · 4 min

模型选择与测试集

Choose a model without leaking the test set.

三模型 A/B/C 的平均验证准确率为 0.79/0.83/0.81；测试准确率为 0.88/0.82/0.85。应依据哪一列选模型？5-fold CV 时能否先在全部五折上拟合缺失值填补器？

展开答案与解析 / Show solution
按验证结果选择 B。测试集只在最终方案确定后用于评估，不能根据测试分数改选 A。每个 CV 训练折内部独立拟合填补器及其他预处理，再应用于该轮验证折。最终可在全部开发数据上重新拟合已选方案。
易错点 / Watch out：多次查看测试成绩并据此改模型，会让测试集变成验证集。
集成学习 Q15 · 5 min

Bootstrap 与 OOB

Estimate OOB probability and explain feature sampling.

从 n 条训练记录中有放回抽 n 次。某记录从未被抽到的概率是多少？当 n 很大时约多少？随机森林除了 bootstrap 还引入什么随机性，目的是什么？

展开答案与解析 / Show solution
未抽到概率=(1−1/n)ⁿ，n 大时约 e⁻¹≈0.368。随机森林在节点分裂时随机选候选特征子集，通常能降低树之间的相关性，使集成更有效地降低方差。OOB 预测只使用没见过该样本的树。
易错点 / Watch out：Bootstrap 样本大小是 n，但通常不含 n 个不同样本；OOB 不是额外收集的测试集。
集成学习 Q16 · 6 min

AdaBoost 一轮权重

Update normalized sample weights after one weak learner.

4 个样本初始权重各 1/4，弱分类器只错第 1 个。标签及预测均为 ±1；α=½ln((1−ε)/ε)，D新(i)∝D(i)exp(−αyᵢhᵢ)。求 ε、α 和归一化后的权重。

展开答案与解析 / Show solution
ε=1/4；α=½ln3≈0.5493。错例乘 e^α=√3，对例乘 e^−α=1/√3。归一化常数 Z=√3/4+3/(4√3)=√3/2。新权重为 (1/2,1/6,1/6,1/6)。
易错点 / Watch out：先乘权重因子，再对全体样本归一化；错例总权重增大，但并非简单加一个常数。
